# P2 实现与统一验收说明

> 实现状态：四批本地开发完成，等待用户统一人工验收后推送并创建 `v0.2.0-p2` 标签。
>
> 更新日期：2026-08-27

## 已实现范围

- 五幕共 30 个线性节点，正常推进约 60 分钟；支持在线、托盘和最长 48 小时离线推进、战败停止、恢复及已完成战斗节点重玩。
- 第四幕开始掉落地图，第五幕最终 Boss 后才显示远征页，且解锁时不会自动把地图入队或启动远征。
- P1 旧档迁移为已通关状态，角色至少 60 级，补足普通天赋点并获得一次免费完整洗点；P2 存档格式为 5。
- 角色与物品统一工作区包含主角/佣兵切换、常驻可折叠装备侧栏、整理背包、仓库、恢复箱、回购、技能石连接、70 节点图形天赋树、AI 和有序掉落过滤器。
- 物品支持悬浮说明、双击换装/卸装、`Shift` 快速转移、拖拽事务和位置相关右键菜单；地图支持双击入队、拖拽排序/跨队及右键移动。
- 远征方针支持路线、失败/满仓行为、最大连续地图、连续失败和仓库剩余格三类停止条件；启用条件按 OR 触发，当前地图使用启动时快照，新方针从下一张地图生效。
- 低密度像素角色、怪物、物品、城镇、战斗和五幕缩略图已接入；图集使用实测非重叠裁切区域，解决相邻怪物串图。
- 界面使用扁平深色主题；字体缩放可在工具栏选择 100%～150% 并持久化；迷你工具栏保持固定可读字号。
- 模拟固定 20 Hz，正常窗口目标 60 FPS，小窗失焦 30 FPS，隐藏到托盘 5 FPS；视觉插值每帧更新，不改变确定性模拟。

## 人工验收路径

1. 运行 `./scripts/verify.ps1 -Launch`，确认标准窗口在 `960×640` 打开。
2. 新建一个存档，观察主线页五幕路线；确认通关前没有远征标签。可用底部 `P2: 模拟48h` 快速走完主线。
3. 通关后确认远征标签出现，地图仍在地图仓库且两支队伍没有自动启动地图。
4. 在“角色与物品”中尝试双击、拖拽、右键、锁定、出售/回购、分解、恢复箱取出和装备侧栏折叠。
5. 查看技能连接、天赋悬浮/搜索/路径规划、AI 以及城镇过滤器；切换到佣兵后确认技能、天赋和 AI 只读而装备可换。
6. 在远征页测试地图拖拽与右键移动、队列排序和方针“下一张地图生效”。
7. 将字体依次切到 100% 与 150%，打开关闭确认框并浏览各页，确认关键按钮可见、文字不重叠。
8. 切换到 `384×216` 迷你窗口，确认按钮文字可读、战斗动画流畅、角色和怪物没有串图；关闭边缘吸附后应可自由拖动。

## 自动验证

统一命令：

```powershell
.\scripts\verify.ps1 -Configuration Debug
.\scripts\verify.ps1 -Configuration Release
```

验证涵盖依赖恢复、编译、全部单元测试、Godot 资源导入和主场景无界面启动。用户确认 `OK` 后再推送四个 P2 本地提交，并创建 `v0.2.0-p2` 标签。

# CampaignB 表现层实现说明

> 状态：本地开发中，等待用户体验验收后提交推送  
> 更新日期：2026-08-27

## 1. 画面与模拟刷新

- 核心世界继续使用确定性事件模拟。
- 在线主循环以固定 `50 ms` 步长推进，即每秒 20 次逻辑更新。
- 可见战斗视图在每个 Godot 渲染帧重绘，并在相邻逻辑状态之间插值。
- 标准窗口和有焦点小窗上限为 60 FPS；失焦小窗为 30 FPS；托盘状态为 5 FPS 低频驱动，只保留事件模拟。
- 调整只影响表现采样，不改变地图种子、战斗结果、掉落或离线结算。

## 2. 背包与仓库

- 主角队和佣兵队各自保留最近一次成功远征的 20 格临时背包快照。
- 临时背包内容随存档持久化；旧 CampaignA 存档缺少该字段时按空背包迁移。
- 城镇装备仓库保持 100 格。
- 三个容器都使用固定格子显示；物品按稀有度显示边框。
- 鼠标悬浮物品格显示底材、物品等级、武器或防御基础值、容量、固有词缀、全部显式词缀和传奇规则。
- 点击仓库物品格后，可以使用原有槽位选择和装备操作。

## 3. 角色被动天赋树

- 26 个 Campaign 节点按重兵、流血、防御、战吼四条分支绘制为固定图形树。
- 连线和节点颜色区分已分配、可分配、未连通与当前选择。
- 小型、显著和规则节点使用不同尺寸与标记。
- 鼠标悬浮节点显示节点类型、分支、分配状态、前置节点和全部效果说明。
- 点击节点后使用“分配”“退还”按钮操作；原有前置、点数、洗点材料和后继节点限制不变。

## 4. CampaignB 生成素材

- 城镇与战斗场景按 `16:9` 视口接入。
- 角色图集覆盖主角外观、装备变化、佣兵、3 类普通敌人、精英变化和 Boss 概念精灵。
- 物品图集覆盖 Campaign 实际掉落的 5 类物品。
- 生成图缺失时保留程序绘制回退，避免损坏资源导致游戏无法启动。
- 当前角色图集用于精细静态精灵和程序化位移/攻击特效；四方向逐帧动作图仍属于 CampaignB 完整美术验收的后续工作，不在本次功能验收中冒充完成。

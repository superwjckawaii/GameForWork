# P7：技能交互与实时性能

## 已确认范围

- 技能页仅保留装备连接孔组与技能石背包；旧技能方案、优先级和高级 AI 数据继续兼容存档，但不在当前界面显示。
- 技能石背包采用 5 列格子；技能石格与已安装孔位悬浮时立即显示名称、类型、等级、经验、标签、效果、消耗、范围、施法、冷却、位置和来源。
- 每个带 `Attack` 标签的主动技能独立选择攻击目标：仅 Boss、仅精英和 Boss、所有敌人。限制只约束对应技能，其他技能仍可清理普通敌人。
- 前台标准窗口目标 60 FPS，失焦迷你窗口 30 FPS，托盘 5 FPS；战斗模拟保持 20 Hz，画面在相邻空间帧间插值。
- 同一目标的伤害数字只合并同一个 50 ms 模拟帧。

## 性能实现

- 新主线战斗时间线和两队新地图预演在后台任务生成；离线结算仍走同步确定性路径。
- UI 不再每帧重复切换窗口模式并整页刷新；背包、装备和天赋节点以内容签名跳过无变化重绘。
- 战斗观察用二分定位空间帧与最近事件，并复用敌人、坐标和事件集合，降低每帧 LINQ 分配。
- 自动存档合并连续请求，JSON 序列化和 SQLite 写入转到单一后台写入任务；切换存档、备份和退出前等待写入完成。
- 测试栏显示 FPS、最近一次模拟耗时和后台存档耗时，迷你窗口不显示。

## 验收边界

- 目标规则与存档恢复由单元测试覆盖。
- P7 不新增技能石筛选、技能方案 UI 或其他高级战斗 AI 设置。
- 音频仍不在当前开发范围。

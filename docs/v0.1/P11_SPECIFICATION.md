# P11：响应式桌面 UI 与交互性能

> 状态：已实现，等待体验验收  
> 存档：不改变权威玩法格式

## 1. 字体与窗口矩阵

字体档位固定为 80、90、100、110、120、130、140、150%，默认 100%。80/90% 用于提高信息密度；小窗使用固定字号。标准窗口 `960×640`、大窗口 `1920×1280` 和自由调整尺寸均不得裁掉关键按钮或最后一行内容。110% 以上允许内部滚动或响应式页签。

## 2. 必修布局

- 纸娃娃在标准窗口完整展示十个装备槽和五个药剂槽；侧栏保留滚动作为大字体兜底。
- 技能页宽度充足时显示背包/孔组双列；装备侧栏打开导致宽度不足时改为上下双区。背包和孔组始终同时可见，两个列表独立滚动并保留底部安全边距，保证跨区拖曳。
- 选择跳过新手教程时，角色与物品、城镇、技能、天赋和 AI 等教程门禁立即全部解除；远征仍只受主线完成这一玩法门槛约束。
- 恢复箱和回购取消 150px 固定裁切，完整显示格子并可滚动。
- 城区图严格保持 16:9，建筑热点使用归一化坐标随画面缩放；七个升级卡使用四列布局，最后一行居中。

## 3. 性能

战斗保持 20Hz 权威模拟与 60FPS 表现。隐藏页面停止复杂刷新；倒计时只更新文本；地图仓、报告、技能、城镇、金属和物品列表只在真实结构变化时重建。自动保存、悬浮、页签切换和退出没有固定周期停顿。

## 4. 验收

- 八档字体可保存恢复。
- 标准/大窗口下装备、技能、恢复箱、回购、城镇均无遮挡。
- 纸娃娃右侧槽留出安全边距，物品图标居中。
- 城区热点与建筑视觉位置对齐。
- Debug/Release、测试、Godot 导入和启动通过。

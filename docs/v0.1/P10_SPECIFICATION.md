# P10：异界终局、复杂天赋树与性能修复

> 状态：已确认并实现  
> 存档格式：12

## 1. 阶段范围

P10 将地图扩展为 T1～T20，加入异界天赋、裂渊、命能花园、赤誓祭坛、苍誓祭坛和第一条高阶 Boss 攻坚链，同时完成 P9 验收发现的周期卡顿、裁切、焦点和拖曳交互问题。

## 2. 性能与界面

- 远征倒计时只更新现有文本，不再进入结构签名；地图仓仅在库存变化时重建，战斗报告仅在展开且报告 ID 变化时重建。
- 隐藏页面停止刷新自身复杂面板；仪表盘低频界面刷新从 10Hz 降至 4Hz，权威战斗模拟频率不变。
- 装备侧栏与金属侧栏可以切换。金属仓采用三列小图标和独立滚动，不再裁掉每行末项。
- 药剂腰带完整显示。装备槽再次点击、点击人偶空白或点击另一槽位都会取消旧焦点。
- 城镇拆分为“城区建筑 / 酒馆名册 / 阵型与事件”，各页独立滚动。
- 主天赋树使用单个 Canvas 和空间索引，不创建 1,600 个按钮；左键越过阈值拖曳，单击选择，左键双击分配，右键双击退还。

## 3. 主天赋树与突破

- 主树共有 1,624 个原创节点，含 30 个主题区、136 个显著节点、34 个专精、38 个规则天赋和 16 个记忆棱孔。
- 普通天赋最多分配 120 点。旧节点稳定 ID 保留，旧档路径继续恢复；失效数据拒绝加载，不自动替玩家选择。
- 专精节点提供三选一效果并持久化。
- 赤铁、翠生、苍风三类原创记忆珠宝提供攻击、生命、移动效果；相邻已分配节点会放大珠宝半径效果。
- 铁誓者拥有 12 节点独立突破树，突破点与普通天赋点分开计算，当前最多四点。

## 4. 异界与攻坚

- T1～T20 每个阶级首次完成提供一个异界天赋点；终局首杀额外提供五点。
- 异界树共有 360 个功能节点，分为地图续航、裂渊、命能花园、赤誓祭坛、苍誓祭坛和攻坚六类。
- 每张完成的地图由确定性种子生成 1～3 条不重复收益路线。命能、赤誓、苍誓资源独立累计并持久化。
- T11 及以上地图产生灰烬天垒碎片，八枚合成一张门票。门票将攻坚排入主角远征并使用实时空间战斗与战斗报告；胜利后记录首杀并发放突破点。

## 5. 验收

- Debug/Release 编译、全部单元测试、Godot 导入和主场景无界面启动通过。
- 旧格式 1～11 存档迁移至格式 12，新天赋选择、珠宝、异界与突破状态往返一致。
- 隐藏战斗报告不会因每秒倒计时发生节点销毁重建。
- 主天赋节点规模与分类下限由自动测试锁定，画布交互不依赖逐节点 Godot 控件。

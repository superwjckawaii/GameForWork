## 2. 已确认共同边界

- “保留效率”影响所有具有保留量的技能，不只影响光环；对法力、生命、护盾或后续合法资源保留使用相同规则。没有保留量的免费技能不从中获益。
- 统一公式为 `最终保留量 = 基础保留量 × 所有更多/更少保留倍率 ÷ (1 + 保留效率提高总和)`；保留效率降低进入同一加法项。最终按对应资源最小单位向上取整，不能把正保留压成 0。
- “诅咒”是上位类型；诅咒效果、持续时间、施加距离、数量上限和针对诅咒敌人的规则同时适用于咒术与标记。只有明确写“咒术”或“标记”的技能自身规则才限定子类。
- 范围属性不能把单体标记改成范围技能；统一诅咒扩散、转移或自动施加仍须遵守同时标记数量与每目标诅咒数量上限。
- “临时增益效果”只缩放由技能产生、带增益标签且具有数值幅度的临时增益。它不缩放光环、药剂、守护、护体、充能、装备/天赋/升华的常驻或二元规则。
- 同一战吼临时增益同时符合“战吼效果”和“临时增益效果”时，两类提高在同一适用加法池各进入一次，不互相相乘，也不能按多个标签重复计算同一条修正。
- 冷却已经归入第五组“触发与冷却”；属性连接点、`+30` 属性大点和来源专属充能归全树布局或原机制来源，不在本组重复建泛用类型。
- 移动技能、反射与荆棘继续不建立普通天赋类型；异常与减益专门防护、护盾充能、击中回复和物理抗性也不能借本组变相补回普通天赋。

## 3. 光环与保留完整节点（已确认）

四个簇均为双入口：左右各两个小点汇入显著，再连接专精。四个专精节点共享 3.5 的七项池，全局不能重复选择同一选项。

### 3.1 战意共鸣（进攻光环）

| 节点 | 最终效果 |
| --- | --- |
| 战意共鸣·小点 ×4 | 你的光环所提供的进攻型数值修正效果提高 `8%`；光环范围提高 `8%` |
| 昂扬主旋·显著 | 你的光环所提供的进攻型数值修正效果提高 `30%`；光环范围提高 `25%`；所有技能的保留效率提高 `12%` |
| 光环与保留专精 | 从共享池选择 1 项 |

进攻型数值包括伤害、速度、命中、暴击、穿透及明确标记的进攻属性；混合光环只放大其中对应行，不重复放大整份光环。

### 3.2 守御共鸣（防御光环）

| 节点 | 最终效果 |

| 光环与保留专精 | 从共享池选择 1 项 |

防御型数值包括生命/护盾/灵障、护甲、闪避、格挡、压制、抗性、减伤与恢复；不会把不存在的防御行凭空添加到光环。

### 3.3 同袍乐章（友军光环）

| 节点 | 最终效果 |
| --- | --- |
| 同袍乐章·小点 ×4 | 你的光环对其他实际参战友军的效果提高 `10%`；光环范围提高 `15%` |
| 万众和声·显著 | 你的光环对其他实际参战友军的效果提高 `35%`；光环范围提高 `40%`；所有技能的保留效率提高 `12%` |
| 光环与保留专精 | 从共享池选择 1 项 |

“其他友军”包括同行佣兵及合法召唤、伙伴、构装单位，不包括主角自身，也不产生后台城镇或远征队收益。

### 3.4 节律精算（全技能保留）

| 节点 | 最终效果 |
| --- | --- |
| 节律精算·小点 ×4 | 所有技能的保留效率提高 `8%`；最大法力提高 `4%` |

| 光环与保留专精 | 从共享池选择 1 项 |

这里的“所有技能”按第 2 节公式覆盖一切合法保留技能；最大法力不改变按最大生命或护盾计算的基础保留百分比。

### 3.5 光环与保留专精共享池

1. **孤奏领域**：你的光环只能影响你；光环对你的效果总增 `50%`。
2. **众声合奏**：你的光环不能影响你；对其他实际参战友军的效果总增 `60%`。
3. **近场共振**：光环半径内侧 `50%` 区域的效果总增 `30%`，外侧区域效果总降 `30%`；按目标当前位置结算。
4. **遥歌播散**：光环范围总增 `100%`，光环效果总降 `20%`。
5. **单曲循环**：只启用 1 个保留技能时，该技能效果总增 `40%`、最终保留量总增 `30%`；启用第二个保留技能后两项立即失效。
6. **复调编排**：同时启用至少 3 个名称不同的保留技能时，这些技能效果总增 `15%`、各自最终保留量总增 `15%`；同名技能只计一个。
7. **血律分担**：原本保留法力的技能把其最终保留量的 `30%` 改为保留生命，剩余 `70%` 仍保留法力；总保留量不降低，任一资源不足时该技能不能启用。

| 末契追猎·显著 | 你对稀有/Boss 施加的诅咒效果提高 `25%`；其上的诅咒持续时间提高 `50%` |

### 4.3 诅咒专精共享池

1. **群咒并书**：每个目标的诅咒数量上限 `+1`；你施加的每个诅咒效果总降 `20%`。
2. **唯一真名**：每个目标最多承受你的 1 个诅咒；该诅咒效果总增 `50%`。
3. **逐魂转契**：被你诅咒的敌人死亡时，其剩余持续时间最长的诅咒转移给 8 单位内最近的合法未诅咒敌人；转移不视为再次施放，并遵守诅咒与标记上限。
4. **永续恶契**：你施加在稀有/Boss 上的诅咒不会自然到期，但效果总降 `15%`；离场、技能禁用或主动替换仍会移除。
5. **先击落印**：你首次击中尚未被你诅咒的敌人时，自动施加技能配置中优先级最高的可用诅咒，效果总降 `50%`；每个目标冷却 4 秒并支付该诅咒正常资源消耗。
6. **临终谕令**：你对低生命诅咒敌人造成 `25%` 更多伤害，对非低生命诅咒敌人造成 `10%` 更少伤害。
7. **逆契护身**：被你诅咒的敌人对你造成 `15%` 更少伤害；你对未被你诅咒的敌人造成 `15%` 更少伤害。

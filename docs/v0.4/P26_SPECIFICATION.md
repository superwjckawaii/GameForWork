# P26 地图系统与金币异界天赋实施规格

> 状态：已确认并实施
> 更新日期：2026-08-30
> 存档格式：v21

## 1. 设计目标

P26 把地图操作收敛为三个动作：用筛选器找地图、选择玩法、开始连续远征。玩家不需要理解“可直接运行”“建议重铸”“高风险高收益”或“危险度”等系统替他做出的分类；所有风险直接显示为词缀、怪物数量、物品数量和玩法强度。

## 2. 地图仓库与统一筛选器

### 2.1 仓库

- 地图按 `T 阶 → 区域` 分组；不再按系统风险分类。
- 地图库存上限 2000 张；Boss 碎片和门票不计入。
- 手动锁定、正在运行、手动优先队列、Boss/任务地图受保护。
- 满仓时先用自动出售筛选器选择未保护地图；无匹配时出售未保护地图中价值最低者。
- 若所有旧地图都受保护，则出售新进入的地图；不会挤掉受保护地图。
- 手动优先队列保留，容量 10，是高于连续远征筛选的明确玩家指令。

### 2.2 筛选字段与语义

筛选器包括：最低/最高 T 阶、最低/最高物品数量、最低/最高怪物数量、区域多选、稀有度、腐化状态、最低品质、必含词缀、排除词缀。

- 不同字段之间为 AND。
- 区域列表内部为 OR。
- 必含词缀必须全部存在。
- 任意排除词缀存在即拒绝。
- 推荐排序固定为：T 阶降序 → 物品数量降序 → 怪物数量降序 → 入库时间升序。
- 连续远征、批量打造、批量出售和满仓自动出售分别保存独立筛选快照，互不联动修改。

### 2.3 连续远征

- 远征指令由“地图筛选器 + 玩法/路线 + 祭坛偏好 + 排序 + 无匹配行为”组成。
- 开始后逐张消耗仓库中符合要求的地图。
- 选定玩法不在地图候选列表时，该地图不匹配；禁止静默改走安全路线。
- 无匹配地图时可选择等待新地图或停止远征。
- 连续远征不会自动打造或自动腐化地图。

### 2.4 出售价格

```text
出售金币 = floor(
  2 + T阶
  + 稀有度奖励（普通0 / 魔法2 / 稀有5）
  + 品质/10
  + 怪物数量/30
  + 物品数量/50
  + 腐化奖励3
)
```

数量项使用界面百分比数值。结果最低为 1 金币。

## 3. 地图稀有度、词缀与数量

### 3.1 固定结构

- 普通：0 条词缀。
- 魔法：1 条危险前缀 + 1 条收益后缀。
- 稀有：2 条危险前缀 + 2 条收益后缀。
- 腐化稀有：在 2+2 基础上追加且只追加 1 条腐化规则。
- Boss 形态组中“王庭护卫/双生王座”互斥。
- 玩法印记组中“裂渊/命能/赤誓/苍誓”互斥。
- 其他高压组合允许共存；不提供反射、完全禁回、伤害免疫词缀。

### 3.2 等级与基础数量

| 等级 | 地图阶级 | 每条危险前缀：怪物/物品 | 每条收益后缀：怪物/物品 |
|---|---|---:|---:|
| R1 | T1～T5 | +6% / +8% | +6% / +10% |
| R2 | T6～T10 | +9% / +12% | +9% / +15% |
| R3 | T11～T16 | +12% / +16% | +12% / +20% |
| R4 | T17～T20 | +15% / +20% | +15% / +25% |

- 每 1% 品质额外提供 1% 物品数量。
- 非腐化稀有上限：怪物数量 +60%，物品数量 +110%（含品质）。
- 腐化稀有上限：怪物数量 +120%，物品数量 +250%（含品质）。
- 最终怪物数 = 基础怪物数 ×（1 + 怪物数量）。
- 每个怪物的掉落预算 = 基础预算 ×（1 + 物品数量）。
- 物品数量作用于装备、金币、金属、地图、技能石和玩法资源；不作用于首次击杀、任务、固定 Boss 门票、异界解锁和保证传奇。

## 4. 地图腐化

- 只有未腐化稀有地图可腐化；腐化后不可再打造。
- 每次必定消耗腐化铁；10% 摧毁地图，地图永久消失。
- 存活的 90% 中四条规则各占 22.5%，且只获得一条。
- 批量腐化必须明确显示概率与摧毁警告；预览不得泄露确定结果。
- 自动远征不会自动腐化；锁定、运行中和手动优先队列地图不能批量腐化。

| 腐化规则 | 效果 |
|---|---|
| 血潮 | 怪物数量 +60%，物品数量 +60%，怪物造成 36% 更多伤害 |
| 贪婪 | 怪物数量 +30%，物品数量 +140%，怪物 75% 更多生命、36% 更多伤害 |
| 失序 | 普通词缀提供的怪物/物品数量翻倍，额外物品数量 +50%；危险前缀效果提高 50%；品质不翻倍，离散的额外 2 投射物仍为 2 |
| 王灾 | 怪物数量 +15%，物品数量 +120%；Boss 150% 更多生命、65% 更多伤害、范围 +80%；转阶段清除可驱散的非永久减益 |

所有结果最终受 +120% 怪物数量、+250% 物品数量上限约束。王灾与双生王座允许共存。

## 5. 120 点金币异界天赋

### 5.1 通用规则

- 删除旧 360 点树、三套方案、方案切换和记忆灰烬切换费用。
- 共 10 类，每类 12 点，前后顺序解锁；可全部购买，无洗点。
- 各类相同位置价格：`100, 200, 300, 500, 800, 1200, 1800, 2800, 4000, 6000, 10000, 20000`。
- 每类合计 47,700 金币，全部 120 点合计 477,000 金币。
- 1～3 点：第五幕通关；4～6 点：完成 T5；7～8 点：完成 T10；9～10 点：完成 T16；11 点：最终突破；12 点：完成 T20。
- 战阵前线整类在 P27 首次遭遇前隐藏。
- 所有提高难度的节点只解锁远征中的可选开关；购买节点本身不强制提高难度。

### 6.3 怪物基线与救援

- 普通：生命/伤害 1.0，掉落预算 100。
- 魔法：生命 1.8、伤害 1.25，预算 250。
- 稀有：生命 5.0、伤害 1.5，预算 800。
- Boss 使用独立曲线，基础预算 3000。
- 地图开始即消耗；普通地图 2 次救援，共 3 次尝试。
- 已清节点保持完成；失败遭遇重开。Boss 只重置当前阶段，已完成阶段保留。
- 最终失败保留已击败怪物的全部普通掉落和经验；不授予地图完成、解锁、首次击杀、固定票券和延迟奖励。
- 高强度深渊和战阵可在其内部明确禁用救援。

## 7. v21 迁移

- 旧地图按稳定种子迁移为魔法 1+1 或稀有 2+2；旧危险度字段忽略。
- 旧队列迁移为手动优先队列；旧远征方针迁移为筛选器 + 玩法。
- 删除旧三套异界方案。每个旧已获得异界点补偿 4000 金币，最多 100,000 金币；已持有记忆灰烬保留为历史资源。
- 超过 2000 张地图时按自动出售规则裁剪并结算金币。
- 正在运行的旧地图使用启动时已固化的旧快照完成，之后全部使用 P26 规则。

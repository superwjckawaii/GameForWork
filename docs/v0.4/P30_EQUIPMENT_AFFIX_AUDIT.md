# P30 装备词缀现状审计与清理清单

> 状态：第一轮审计及五项问题全部确认；后续改为一次性统一提案，尚未实施运行时代码
> 更新日期：2026-09-01
> 权威规则：[`P30_SPECIFICATION.md`](P30_SPECIFICATION.md)

## 1. 审计结论

当前自然词缀池由三套历史数据直接拼接，并不是一张已经统一的正式表：

| 数据层 | 家族数 | 分级记录数 | 结论 |
| --- | ---: | ---: | --- |
| P1 `core.affix.*` 临时词缀 | 45 | 87 | 全部退出 P30 自然词缀池 |
| P19 PoB 快照映射 | 55 | 345 | 单属性家族多数可保留数值；复合、局部、格挡和药剂家族必须重建真实语义；5 类失效并删除 |
| P24 职业机制词缀 | 45 | 135 | 44 类保留设计身份但全部重建真实字段与数值；`法武`删除 |
| **合计** | **145** | **567** | 当前记录不能直接作为 P30 正式表 |

主要问题不是个别 T 级偏高，而是显示、生成和实际结算不一致：

- `Local=true` 目前仍被汇总为全身全局提高，没有进入 P30 的武器/防具局部公式。
- 一条 `AffixDefinition` 只能保存一个数值。双区间附加伤害、双防御、固定防御＋生命等复合词缀被压扁为单一整数。
- P24 用现有枚举借位表达完全不同的效果，例如投射物速度借用攻击速度、诅咒效果借用物理伤害、召唤物生命借用角色生命。
- “提高格挡概率 76%～81%”被当作“格挡概率 +76～81 个百分点”，会直接撞上格挡上限。
- 药剂恢复量、恢复速度、充能消耗、跨资源代价和瞬回全部借用同一个“生命药剂效果”字段，实际规则缺失。

因此本轮固化清理边界和初步数值判断；正式表必须扩展为多数值、明确作用域和明确伤害/单位/技能标签的数据结构。后续不再逐装备类型确认，统一见 [一次性修改提案](P30_EQUIPMENT_AFFIX_FINAL_PROPOSAL.md)。

## 2. 已直接删除或禁止进入正式表的内容

以下项目不再作为后续讨论候选：

1. 删除全部 45 个 `core.affix.*` 家族。它们是 P1 两档测试词缀，数值只有 `+4～18 生命`、`+8～35 命中`等，并与 P19 正式家族重复；P19 规格也已明确它们不得再进入自然掉落池。
2. 上述旧层包含的三种 `core.affix.*.extra_link` 同样不保留。孔数、连接数和重铸由底材、孔组及金属加工负责，不再作为普通自然前缀。
3. 删除下列 5 个含“眩晕与格挡恢复”的 P19 复合家族。游戏没有对应的受控恢复时间结算，保留其中的低档局部防御只会与纯防御前缀重复：
   - `localarmourandenergyshieldandstunrecovery`
   - `localarmourandevasionandstunrecovery`
   - `localenergyshieldandstunrecoverypercent`
   - `localevasionratingandstunrecoveryincreasepercent`
   - `localphysicaldamagereductionratingandstunrecoverypercent`
4. 删除 `p24.affix.rune.spellblade`（法武）。它把法术伤害转成攻击伤害，违反 P30“主动伤害技能的攻击与法术互斥”及已确认的有向伤害类型转化图。
5. 给正式词缀生成器设置硬黑名单：
   - 偷取总恢复量提高；
   - 偷取持续时间提高/降低；
   - 击杀回复。

当前 567 条数据中没有后三类自然词缀记录，因此此项是防止后续从 PoE 数据或旧设计重新导入；升华、传奇和技能中写明条件的规则型击杀恢复不受影响。

## 4. P24 职业机制词缀审计

P24 的 45 个家族全部使用统一的 `3%～15%` 数值模板，不区分百分比、固定上限、额外投射/单位数、持续时间或规则开关，因此现值没有可比性。P30 正式表按下列方式处理：

| 主题 | 现有家族 | 审计结论 |
| --- | --- | --- |
| 投射 | 额外投射、投射物速度、穿透、远距离伤害、标记效果 | 全部保留身份并改为真实投射/标记字段；“额外投射”当前实际是附加物理伤害，必须改名或明确是伤害而非数量 |
| 暗影 | 背袭、中毒、陷阱上限、移动后闪避 | 保留身份；中毒不得再借用流血概率，陷阱上限不得借用连接容量 |
| 召唤 | 召唤物上限、伤害、生命、行动速度、光环效果 | 保留身份；全部改为召唤物专属字段，不能增强主角 |
| 诅咒 | 效果、持续时间、传播半径、保留 | 保留身份；咒术与标记共用“诅咒”标签规则，保留效率影响所有保留技能 |
| 法术 | 元素法术、虚空法术、施法速度、最大护盾、护盾充能 | 保留身份；攻击与法术字段严格互斥，元素与虚空不得借用物理提高 |
| 禁术 | 凋零、护盾偷取、护盾支付、屏障 | 保留身份；按 P30 凋零、35% 护盾偷取总上限、最终法力消耗转付和屏障规则重建 |
| 徒手 | 徒手附加、连击时间、姿态、幻身上限 | 保留身份；不得污染持武器攻击，幻身上限使用独立字段 |
| 灵兽 | 伙伴伤害、生命、复生、夹击 | 保留身份；核心伙伴不继承普通召唤物词缀 |
| 行者 | 位移技能冷却恢复 | 保留身份；移动技能没有普通天赋簇不等于装备不能提供该效果 |
| 符文 | 刻印、触发冷却、法武、魔铠 | 刻印/触发/魔铠保留；`法武`删除，不允许法术伤害转换为攻击伤害 |
| 构装 | 构装上限、伤害、生命、Boss 优先、重铸 | 保留身份；全部改为构装专属字段 |

这些机制词缀只能在匹配的特殊底材上自然生成。正式实现前，当前借位属性不得视为其真实战斗效果，也不能用于 36 套构筑审计。

## 5. 第一轮问题确认状态

### 5.1 武器局部高强度核心词缀（已确认）

有些 T1 局部核心词缀可以远高于普通全局词缀。纯局部物理提高允许沿用 PoE 式数值，使白底武器达到约 2～3 倍基础物理伤害；不再使用“所有 T1 局部词缀只提升 15%～25%”的统一限制。

### 5.2 胸甲最高档固定生命（已确认）

保留当前 T1 `+175～189`。以 100 级、150 体魄角色为例，未修正生命为 `1030`，该词缀约提高 17%～18%，符合高阶胸甲核心前缀定位。盾牌当前最高只能取得较低档，正式表继续按槽位分别编号。

### 5.3 生命恢复（已确认）

自然装备统一使用“每秒恢复 X% 最大生命”，T1 为 `1.8%～2%`；少量底材固有、传奇和规则型装备可以继续使用固定恢复。

### 5.4 盾牌局部格挡提高（已确认）

保留 `76%～81% increased` 的原始身份，按盾牌基础格挡局部乘算。例如 25% 基础格挡经过 80% 局部提高成为 45%，而不是 `25% + 80% = 105%`。最终再叠加角色全局攻击格挡并受上限约束。

### 5.5 P24 机制词缀的来源（已确认）

44 个保留家族继续作为匹配特殊底材的自然词缀，但不进入所有普通装备的通用池；工坊附魔只提供已明确列入附魔表的机制，不允许绕过底材身份。其 T1 预算和权重改由一次性修改提案统一审核。

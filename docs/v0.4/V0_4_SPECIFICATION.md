# GameForWork v0.4 玩法与数值打磨总规格

> 状态：已确认，P26～P29 已实施；P30 设计确认中
> 更新日期：2026-09-01

## 1. 版本目标

v0.4 不再扩充职业数量，集中把已有构筑放进稳定、可持续、可读的完整玩法循环。版本完成时，玩家应能从五幕主线自然进入异界，通过轻量地图仓库、地图打造、远征指令和异界天赋持续推进，并能明确判断难度、收益与构筑短板。

## 2. 范围

1. 以主角、佣兵和召唤物的真实成长曲线重新标定五幕剧情与 T1～T20 怪物。
2. 完成地图仓库、统一地图筛选器、地图打造/出售、连续远征和 120 点异界天赋。
3. 五幕主线分别建立一个怪物族群；深渊、命能花园、赤誓、苍誓和后续战阵分别建立独立族群与战斗身份。
4. 重做怪物掉落池、掉落率、地图续航和玩法专属奖励。
5. 打磨天赋、十八升华、装备词缀与技能数值，删除无效机制并增强构筑分化。
6. 为装备效果和技能补充可辨识、统一风格的动画与反馈。

## 3. 开发阶段

- P26：地图系统、地图数值、地图筛选器、连续远征、地图打造/出售、腐化、120 点金币异界天赋。
- P27：五幕与异界怪物族群、战阵玩法首次出现、剧情/异界怪物数值标定（已实施）。
- P28：深渊、命能花园、赤誓、苍誓与战阵差异化打磨（已实施，见 `P28_SPECIFICATION.md`）。
- P29：完整掉落池、地图续航、玩法资源与经济审计（已实施，见 `P29_SPECIFICATION.md`）。
- P30：统一战斗公式、天赋、升华、装备词缀、技能和 36 套构筑平衡；基础公式、怪物标定及前三组天赋（45 类、125 簇）设计已确认，尚未实施。总规则见 [P30 总规格](P30_SPECIFICATION.md)，换设备继续时先读 [当前进度与剩余内容](P30_DESIGN_CHECKPOINT.md)，下一步确认单位组类型与簇数。
- P31：装备效果、技能动画、战斗反馈、性能与 v0.4 封版。

阶段编号只用于持久化依赖和验收，不要求拆成大量零散发布。

## 4. 跨阶段规则

- 游戏没有战斗限时失败；时间仅用于构筑效率报告。
- 战斗失败仍结算已经击败怪物的经验、装备、金币、金属、地图、技能石和玩法资源；不授予地图完成、首次通关、固定门票或延迟奖励。
- “提高”进入同一加法乘区；每个“更多”进入独立乘区；“总降/更少”以乘法降低。
- 第四抗性统一称为“虚空抗性”，不使用“混沌伤害/混沌抗性”。
- 高难度必须来自明确可见、可选择的规则，不使用抽象“危险度”掩盖实际效果。

## 5. v0.4 完成定义

- 标准构筑可按目标成功率和战斗时长推进五幕、T1、T6、T11、T16、T20。
- 地图仓库稳定容纳 2000 张地图；筛选、打造、出售和无人值守远征使用同一语义且各自保存快照。
- T1～T20 无异界天赋基础续航与满地图续航达到 P26 目标。
- 五幕族群和五个玩法族群拥有不同技能、队形、抗性与掉落身份。
- 六职业十八升华至少各有一个通过自动审计的主流构筑；关键机制均有实际结算和战斗报告证据。
- 完整验证入口、单元测试、经济审计、Godot 无界面启动和人工 UI 验收全部通过。

# Monsters 怪物生态、首领与亡旗战阵实施规格

> 状态：已确认并实施
> 版本：v0.4
> 依赖：Atlas 地图仓库、地图筛选器、地图路线与金币异界天赋

## 1. 目标与边界

Monsters 把五幕和异界从“同一批怪物随等级放大”改为可辨认的十族生态，并首次开放亡旗战阵。Monsters 完成怪物身体素材、基础技能逻辑、明确伤害类型、首领目录、战阵发现和基础战功结算；高级技能特效、命中特效和终局动画仍由 Presentation 完成。

掉落池的逐怪精确权重属于 Resources，祭坛、花园和裂渊的完整奖励差异属于 Encounters。Monsters 只提供这些玩法所需的专属敌族与可靠战斗入口。

## 2. 十族与八十种非首领怪物

每族固定八种非首领怪物，总计八十种：

| 来源 | 族群 | 战斗身份 |
| --- | --- | --- |
| 第一幕 | 烬骸军团 | 物理/火焰、冲锋、战旗 |
| 第二幕 | 霜原猎群 | 冰霜、包围、冰缚区域 |
| 第三幕 | 沉墓亡者 | 骨矢、尸体利用、钟波 |
| 第四幕 | 血炉造物 | 高护甲、熔炉区域、修复 |
| 第五幕 | 虚空教团 | 虚空投射、延迟爆发、召唤 |
| 裂渊 | 裂渊异兽 | 钻地、追猎、递增强度 |
| 命能花园 | 命能孽种 | 根须禁足、孢子、群体治疗 |
| 赤誓祭坛 | 赤誓刑团 | 流血、献祭、处决 |
| 苍誓祭坛 | 苍誓星侍 | 雷霜、延迟法术、护盾链接 |
| 亡旗战阵 | 亡旗军阵 | 盾墙、压制齐射、炮击、号令 |

旧四十八种怪物保留稳定 ID 和顺序，并补充族群标志技能；新增三十二种怪物使用 `monsters.enemy.*` 稳定 ID。每种怪物至少有一项技能，大多数怪物轮换两项技能。技能记录名称、物理/火焰/冰霜/闪电/虚空伤害类型、倍率、施放间隔、距离、范围、预警和是否可规避。

## 3. 怪群生成规则

- 五幕继续按幕使用对应主线族群。
- 十二张地图各自绑定两个主题族群；普通节点在两族之间确定性选择。
- 裂渊、花园、赤誓、苍誓和亡旗节点强制使用各自专属族群。
- 怪群不使用“前排 + 后排 + 支援”的强制预制结构。
- 合法结果包括整群同一种怪、整群远程怪、整群支援怪、整群召唤怪、单一职责怪群，以及自然混合怪群。
- 生成器先确定同种、同职责或完整族群池，再从该池生成实例；因此极端怪群是正式构筑压力，而不是异常回退。

## 4. 战斗能力

- 每个实例按自己的技能序列循环，而不是永远重复第一项技能。
- 元素与虚空技能按技能伤害类型读取对应抗性；不再用怪物族群猜测抗性。
- 范围技能受地图范围和范围伤害词缀修正；投射/法术继续受额外投射物规则修正。
- 战旗/战鼓对存活友军提供伤害增益。
- 命能绽放和战地修复会恢复技能范围内存活友军生命。
- 预警信息写入战斗事件，包含技能名、预警形状、伤害类型和可规避性，供 Presentation 渲染高级表现。
- 纯支援怪群允许出现，但支援怪仍保留低伤害技能或轮换技能，不形成永久无解战斗。

## 5. 区域首领

- 五幕各有一个稳定首领：余烬守门人、谷仓吞噬者、溺亡圣徒、无光领路人、界外之物。
- 十二张地图各有唯一首领，名称与地图目录一一对应，不再由八个首领回退复用。
- 每个普通地图首领至少三项带预警技能，并保留阶段阈值和狂暴时间。
- 百级门扉和灰烬天垒三阶段首领保持原有入口。
- 亡旗战阵增加铁旗校尉、烬炮监军两名军官和末旗统帅。

## 6. 亡旗战阵

### 6.1 发现

- 完成 T5 后，地图仓库中的第一张 T6+ 地图保证追加亡旗战阵候选路线；仓库没有合格地图时生成一张 T6 发现地图。
- 第一次进入战阵后即视为发现；即使挑战失败，也保留发现状态和部分战功。
- 发现前，战阵异界天赋分支隐藏；发现后显示并允许按 Atlas 金币规则购买。
- 发现后，T6+ 新库存地图以稳定规则获得战阵候选，不因重载存档变化。

### 6.2 五节点路线

1. 侦察接敌；
2. 突破前线；
3. 战地补给抉择；
4. 随机军官阵地；
5. 末旗统帅本阵。

祭坛是地图的附加属性，可与战阵同时存在；选择战阵不会清除赤誓或苍誓祭坛。

### 6.3 基础结算

- 失败：发现战阵，并获得 `地图 T 阶 x 3` 战功。
- 成功：获得 `地图 T 阶 x 10` 战功，以及 `1 + T 阶 / 5` 声望。
- 战功、声望、发现状态和保证地图发放状态全部进入存档。
- 战阵专属装备、逐层军需选择和精确掉落权重在 Encounters/Resources继续实施。

## 7. 美术与图集

- 新增五列两行、十套正式怪物身体素材：裂渊、花园、赤誓、苍誓、亡旗各两套轮廓。
- 素材沿用 Art 暗黑低密度像素风、底部中心锚点与透明留白。
- 敌方身体骨架由 16 套扩为 26 套，动画图集为 31 列、104 行、单元 48 x 64。
- 八十种怪物稳定映射到图集；旧前四十种怪物维持原映射，裂渊及四个新玩法族使用对应新素材。
- 构建审计逐格检查透明边距、尺寸和清单数量。

## 8. 验收标准

- 十族各八种怪物，总计八十种，稳定 ID 不重复。
- 所有怪物至少一项有效技能，且明确伤害类型和倍率。
- 自动测试证明生成器可生成同种纯怪群和纯支援怪群。
- 十二张地图均有两个主题族群和唯一首领。
- 亡旗战阵严格为五节点，军官与统帅节点使用专属首领。
- 失败发现、部分战功、成功战功/声望均能保存和恢复。
- 26 套敌方身体图集通过尺寸与透明边距审计。
- Debug/Release 构建、全部单元测试和 `verify.ps1` 均通过。

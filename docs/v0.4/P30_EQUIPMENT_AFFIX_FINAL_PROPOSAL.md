# P30 装备词缀一次性修改提案

> 状态：已审核；装备目录、复合字段、局部结算、特殊词缀、固定传奇、附魔与专项测试已实施
> 更新日期：2026-09-01
> 前置：[现状审计与清理清单](P30_EQUIPMENT_AFFIX_AUDIT.md)、[P30 总规格](P30_SPECIFICATION.md)

## 1. 目标与审核方式

本文件不再按武器、防具、首饰逐轮确认，而是把已确定的天赋、十八升华、珠宝、单位、技能机制、美德/恶德和 P29 特殊底材一次映射到装备系统。用户审核本文件后，它直接成为 P30 装备数据与结算实施依据；后续只通过 36 套构筑审计做数值微调，不重新逐装备类型讨论。

普通装备仍采用 PoE 式设计：高阶核心词缀可以非常强，T1 纯局部物理提高允许使白底武器达到约 2～3 倍基础物理伤害。不同词缀按自身身份分配预算，不设置“所有 T1 只能提升相同比例”的统一上限。

## 2. 确定删除

### 2.1 自然词缀

1. 删除全部 45 个 P1 `core.affix.*` 临时家族及 87 条记录。
2. 删除 5 个“局部防御＋眩晕与格挡恢复”复合家族；游戏没有对应恢复时间结算。
3. 删除 P24 `p24.affix.rune.spellblade`。法术伤害不能转成攻击伤害，攻击与法术标签保持互斥。
4. 普通自然词缀永久禁止：偷取总恢复量提高、偷取持续时间提高/降低、击杀回复。
5. 删除普通自然“额外连接容量”。孔数、连接和重铸只来自底材、金属加工、指定附魔或特殊固定底材。

### 2.2 不再进入普通随机池的规则

下列效果只能来自技能、专精、升华、腐化、附魔、传奇或固定特殊底材：

- 独立更多伤害、行动速度、反转/无视护甲、处决、Boss 阶段跳过；
- 美德/恶德获取或常驻、最大层数、每层效果强化；
- 100% 瞬偷、全部伤害转化、额外攻击/法术格挡上限；
- 死亡自爆、异常传播、持续伤害提前引爆、复演、合击和递归触发规则；
- 四种最大抗性同时提高、额外核心技能容量；
- 反射与荆棘。P30 已排除该构筑方向，不新增换名词缀。

## 3. 数据模型必须修改

当前单一 `ModifierKind + MinimumValue + MaximumValue` 无法实现已确认设计。正式词缀改为包含一个或多个组件：

- 每个组件独立记录属性类型、最小/最大值、显示精度和单位；
- 明确 `Flat / Increased / More / Less / ChancePoint / BaseValue / Conversion / ExtraAs / Rule`；
- 明确 `LocalWeapon / LocalArmor / GlobalCharacter / SkillTag / UnitTag / Flask / Conditional` 作用域；
- 附加伤害分别记录“最小值下界、最小值上界、最大值下界、最大值上界”四个数值；
- 攻击格挡、法术格挡、法术压制分别建字段；“格挡提高”与“格挡概率 +X 个百分点”不能共用字段；
- 攻击速度、施法速度、行动速度和移动速度分别建字段；
- 攻击、法术、召唤物、伙伴、构装、陷阱、幻身属性不得借用角色物理伤害或生命字段；
- 前后缀、互斥组、适用底材标签、伤害/技能/单位标签、来源和权重由数据定义，不再通过显示文本猜测；
- 条件型或规则型效果保存稳定 Rule ID，在线、离线、48 小时模拟和战报读取同一实现。

局部结算固定为：

```text
(底材基础 + 局部附加) × (1 + 局部提高) × (1 + 品质)
```

武器分别计算伤害上下界；护甲、闪避、护盾和灵障分别计算。局部结果不能再次作为全局提高相加。

### 5.6 药剂

保留 P19 的 PoE 式药剂路线，并拆成真实字段：

- 恢复量、恢复速度、持续时间；
- 充能获取、每次使用充能消耗、充能返还；
- 部分瞬回、结束时瞬回、满资源后是否继续；
- 药剂期间护甲、闪避、暴击、移动速度；
- 解除或避免指定异常/诅咒；
- 跨资源代价必须完整结算，自动 AI 在使用前检查会不会直接造成死亡。

T1 生命再生装备词缀为每秒 `1.8%～2%` 最大生命，不与药剂恢复量混用。

| 冰霜转火焰 / 闪电转火焰 | `15%～25%` | 80 |

这些家族使用同一转化互斥组和合法边检查：同一来源类型转出超过 100% 时同比归一；额外获得不消耗原伤害；禁止任何逆流、循环或法术伤害转攻击伤害。

传奇或固定特殊底材可以提供更高比例，但必须写明代价或槽位机会成本。已确认的转伤传奇珠宝保持原值，不与普通装备词缀合并。

### 9.2 传奇装备

- 37 件现有传奇/神话、P29 玩法传奇及新增美德/恶德传奇全部进入 36 构筑与固定种子测试。

## 10. 特殊底材与固定基底

P29 战功底材及现有底材隐式不删除，但必须改为多组件真实数据：

- 四抗、双属性、三防御、药剂效果＋充能、技能石等级等每一项分别结算；
- “攻击与施法速度”“主动与辅助等级”等不能只实现文本中的一半；
- `决胜印戒`等固定更多伤害属于特殊底材预算，不进入普通随机池；
- `三誓指环`四种最大抗性和四抗完整生效；
- `元帅敕令`核心容量与辅助容量分别实现；
- 战功底材继续比普通同档底材强，但强度来自固定隐式和槽位机会成本，不额外获得隐藏掉率加成。

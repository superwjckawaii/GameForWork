# P31 表现、性能与 v0.4.0 封版规格

> 状态：已实施，等待玩家侧复核
> 确认日期：2026-09-02
> 版本目标：GameForWork v0.4.0

## 1. 阶段目标与边界

P31 是 v0.4 的最后阶段，负责把 P26～P30 已完成的玩法、战斗公式和构筑系统收束成可发布的完整版本。P31 不新增职业，不重开 P30 数值设计，不新增联网、玩家交易、音频或第三远征队。

亡旗战阵已经属于 v0.4；沉金港与无光矿脉延期到 v0.5。旧文档中“二者延期到 v0.4”的表述由本阶段统一修正。

## 2. 装备表现

- 战斗角色使用分层装备表现：主手按剑、斧、锤、匕首、弓、法杖、符刃、徒手分类，副手区分盾牌与其他副手，头盔和胸甲提供可见轮廓。
- 底材阶级改变材质明度与装饰数量；稀有度提供边缘色；火焰、寒霜、闪电、虚空局部伤害或附魔提供低强度元素辉光。
- 关键传奇使用稳定 ID 对应的专属颜色/轮廓组合。P31 不为每个随机装备实例制作一张独立角色动画。
- 角色纸娃娃、拖拽预览、物品格与战斗覆盖层使用同一套装备视觉身份。

## 3. 技能与辅助表现

- 为 86 个主动技能建立数据驱动的视觉描述，至少包含表现族、主/辅色、作用半径、持续时间、投射物数量、轨迹、命中形态和屏幕震动强度。
- 表现族覆盖：近战斩击、突刺、旋转、重击震波、直线投射物、散射/齐射、返回/连锁、法术弹体、光束/引导、新星/范围爆发、持续地面、陷阱、召唤/构装、光环/守护/战吼/战旗。
- 十八套终局构筑的主技能与 Boss 技能使用专属多阶段表现；其余技能可以共享表现族，但颜色、尺度、节奏或轨迹必须至少有一项可辨识差异。
- 98 个辅助技能不各自制作独立动画。连锁、穿透、多投射物、范围、重复、爆炸、异常强化等可见机制通过覆盖层和表现参数改变主技能。
- 攻击和法术视觉身份互斥；表现只读取已经结算的技能事件，不产生第二套伤害逻辑。

## 4. 战斗反馈

- 命中、受击、暴击、未命中、闪避、格挡、法术压制、免疫和死亡均有明确但短促的反馈。
- 伤害数字按 50ms 结算窗合并；物理、火焰、寒霜、闪电、虚空和持续伤害分色，暴击同时使用尺寸/符号强调，不能只依赖颜色。
- 血条附近只显示当前实际存在的流血、中毒、点燃、冰缓、冻结、感电、侵蚀、凋零、破甲以及美德/恶德层数。
- 稀有怪词缀提供不遮挡主体的标记。Boss 预警区域、蓄力、释放、命中和阶段切换与实际判定位置、半径和时间一致。
- 节点结算显示短暂收益条，只展示过滤器保留的装备以及传奇、技能石、珠宝、地图、金属和 Boss 碎片；同类资源合并。

## 5. 显示设置与窗口规则

- 新增特效密度：低 / 中 / 高，默认中。
- 新增伤害数字：关闭 / 合并 / 完整，默认合并。
- 新增屏幕震动开关，默认关闭。
- 小窗自动使用低密度表现，但不改变战斗模拟；标准窗与大窗遵循玩家设置。
- 托盘继续使用 5 FPS 限帧；恢复可见窗口后立即回到 60 FPS。
- 不实现音频。

## 6. 像素素材

- 延续清晰、低密度、接近 Taskbar Hero 可读性的暗黑像素风，避免依赖亚像素细节。
- 新增装备覆盖层、技能特效图集、状态图标、Boss 预警与命中特效。
- 原始生成图只用于形态和配色来源；进入运行时的图集必须经过确定性网格、透明边界和最近邻缩放处理。
- 所有新增素材写入清单，校验尺寸、透明通道、切片边界和稳定哈希；缺少素材时保留程序绘制回退。

## 7. 性能门禁

- 可见窗口目标 60 FPS，正常运行不得出现固定约一秒的周期性卡顿。
- 常规战斗峰值帧耗时不超过 40ms，UI 单次刷新不超过 16ms。
- 24 个敌人、连续投射物与完整伤害数字压力场景仍可操作。
- 托盘模式平均 CPU 低于 1%；30 分钟稳定运行没有持续性内存增长。
- 48 小时模拟、切页、拖拽和退出不能阻塞主界面。
- 战斗事件使用有界缓冲与表现对象复用；渲染插值不修改固定步长模拟结果。

## 8. UI 与实屏验收

- 检查标准窗、大窗、小窗，80% / 90% / 100% 字体以及 Windows 150% DPI。
- 覆盖总览、主线、远征、地图仓与制图、角色装备、打造、珠宝、Boss 碎片、技能、三类天赋、城镇和所有独立窗口。
- 动态文本不得改变按钮宽度并挤压相邻组件；弹窗、滑动区域、提示框、底部按钮和右侧栏不得裁切。
- 低密度特效下仍需保留 Boss 预警、角色/敌人血条和关键防御反馈。

## 9. 存档与发布

- v0.4.0 建立正式存档架构版本；旧测试存档不保证迁移。
- 无法加载的旧存档复制到 `recovery/`，永久保留最近 10 份，随后创建新档；不得覆盖原始损坏文件。
- 从 v0.4.0 起开始维护向后兼容。
- Release 版隐藏测试倍速和开发诊断；Debug 版保留。
- 发布物为 `GameForWork-v0.4.0-win-x64.zip`，包含可执行文件、README、版本说明和 SHA256。
- GitHub Actions 对 `v0.4.*` 标签执行 Release 验证并上传便携包。
- 清理测试残留、失效资源和用户可见的外部游戏名称；记录第三方工具/数据来源与生成素材说明。

## 10. 完成定义

P31 必须同时满足：

1. 86 个主动技能均有视觉描述，十八个基准主技能和所有 Boss 主动技能有可辨识表现。
2. 装备覆盖层、辅助石可见机制、异常/防御反馈和过滤后收益条进入实际战斗界面。
3. 新存档可完成五幕、T1、T10、T16、T20、两种固定 Boss 和五种地图玩法。
4. 装备打造、过滤器、珠宝、Boss 碎片、离线 48 小时、托盘、恢复箱与正常退出通过验证。
5. 自动测试、36 构筑审计、经济审计、素材校验、Godot 导入/启动、压力测试和实屏矩阵全部通过。
6. v0.4.0 便携包能在独立目录启动，版本号、图标、说明与校验值正确。

## 11. 开发侧验收结果

- 86/86 主动技能视觉描述、18 个终局主技能专属多阶段标记、98/98 辅助机制叠层通过自动测试。
- P21 与 P31 素材图集通过尺寸、透明隔离、非空格与稳定哈希校验；P31 运行时图集为 4×4、每格 64×64。
- Release 编译零警告；390 项测试、P29 经济审计、P22 战斗审计和 P30 的 36 套构筑审计全部通过。
- Godot 4.7.2 .NET 导入与无界面启动通过；v0.4.0 Windows 便携包导出成功。
- 15 秒可见窗口采样峰值帧耗时 16.80ms、工作集增长 13.8MB；60 秒托盘采样平均 CPU 0.23%、工作集增长 5.1MB；48 小时等效离线测试通过。
- 实屏检查覆盖标准窗口战斗、显示设置、角色与物品、技能孔组/背包和迷你窗口；发现并修复迷你窗口关闭确认框裁切。其余页面沿用 P30 全矩阵验收结果。

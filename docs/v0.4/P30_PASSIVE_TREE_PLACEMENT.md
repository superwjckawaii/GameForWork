# P30 主天赋树主题簇固定落位

> 状态：固定布局已确认，尚未实施
> 更新日期：2026-09-01
> 所属阶段：P30

## 1. 落位目标与稳定编号

- 本表为 131 个中型簇和 37 个大型簇指定唯一所属区域、视觉层带、顺序和入口槽位；布局已经确认，实现不得再按主题随机分配。
- 六个区域沿主树顺时针排列：`V0 斗士`、`V1 隐士`、`V2 秘术师`、`V3 灵能使`、`V4 僧侣`、`V5 侠客`。
- 每区中型簇使用三条视觉层带：`I` 为靠近内环的内层带，`R` 为中环及径向通道带，`O` 为靠近外环的外层带。编号从该区域逆时针边界向顺时针边界递增。
- `V0～V4` 每区采用 `I01～I08 + R01～R07 + O01～O07 = 22` 个槽位；`V5` 采用 `I01～I07 + R01～R07 + O01～O07 = 21` 个槽位。
- 槽位是拓扑数据的一部分。最终坐标可以为了避让做小幅像素级调整，但不能交换槽位主题，也不能改变入口锚点顺序。
- 同一层带中相邻编号代表相邻入口方向；不同层带之间没有默认相邻关系。每个槽位只连接一个属性路径入口，簇与簇不直接连线。

## 2. 中型簇入口节奏

- `I`、`R`、`O` 三带分别沿所在环带或径向通道排布，簇体朝区域扇形内部展开，不能覆盖属性边、属性大点或相邻簇。
- 同一层带的入口采用“相邻挂接与留空交替”的节奏：允许两处连续属性点分别挂接不同主题，但连续挂接不得超过 2 个；之后至少空出 1 个属性路径点。
- 同一主题的两个中型簇必须分处不同层带，或在同层带至少隔开 2 个其他主题槽位。下表已经满足这一约束，实施时不能因自动排版将其重新贴邻。
- 四个属性中型簇位于对应纯属性区域的 `I01`：体魄在 `V0`、能量在 `V2`、精神在 `V3`、灵巧在 `V5`。它们作为职业早期可见但非必经的支路。

## 9. 外环大型簇入口模板

- 外环边编号为 `E0=V0→V1`、`E1=V1→V2`、`E2=V2→V3`、`E3=V3→V4`、`E4=V4→V5`、`E5=V5→V0`。
- 每条边的 11 个中间属性点编号 `P01～P11`。六个美德/恶德簇固定接在 `P06`，即几何中点。
- `E0` 使用 7 个入口：`P01/P03/P05/P06/P07/P09/P11`；其余边各使用 6 个入口，并交替使用两种稀疏模板：
  - 模板 A：`P01/P03/P05/P06/P08/P10`；
  - 模板 B：`P02/P04/P06/P07/P09/P11`。
- `E1/E3/E5` 使用模板 B，`E2/E4` 使用模板 A。这样只有中点附近出现一组连续入口，其余入口之间均留有至少一个空属性点。
- 大型簇整体朝外展开；相邻边靠同一顶点的最外侧簇必须在坐标生成时错开径向距离，不能在顶点外侧重叠。

## 12. 审核后实施数据要求

审核通过后，将本表转换为唯一机器数据源；至少包含：

```text
cluster_id
cluster_size
sector_id
band_or_edge
slot_or_anchor
entry_node_id
orientation
topology_template_id
mastery_exclusion_key
```

坐标生成、底图、点击判定、拖动缩放、连接线和存档分配都读取同一数据。任何簇因美术避让移动后，底图预留位与运行时节点必须一起重生成，禁止只改图片或只改控件坐标。

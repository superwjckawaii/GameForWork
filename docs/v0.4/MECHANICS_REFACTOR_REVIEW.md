# 机制修复与领域重构复核

日期：2026-09-05

本轮继续修复已确认设计。**遗留项尚未全部关闭，继续修复后再讨论 v0.5。**

## 已完成的重构与修复

- 代码、文档、脚本、测试、工具和资源引用改为领域名称；修复重命名造成的命名空间冲突、节点坐标编号损坏、百分比格式损坏、音频扩展名误替换、脚本编码错误和悬空客户端标识文件。
- 主角技能统一进入 `ResolveHeroHit` 与 `DamagePacketRules`，移除早期独立纯物理结算、重复类型增伤和仅供测试使用的转换归一函数。装备九条转换边与四类额外伤害进入实际伤害包，按历史类型阶段计算提高，满额转换不残留舍入产生的物理分支。
- 额外伤害适用于对应的原始和转换后元素分支。实际重击对照验证全物理转火后使用火焰抗性；另覆盖多阶段提高、元素额外虚空、过量转换及舍入守恒。
- `ProjectileSimulation` 独立处理飞行位置、穿透、分裂、连锁和返回；去程与返程分别维护命中集合，保存发射时构筑、技能和装备动作状态。返回没有未经设计的统一伤害惩罚，额外连锁读取发射动作状态。
- 合猎箭匣按不同动作攒层，强化动作的全部投射物可以命中主目标，首枚以后总降 60%；换主目标和战斗结束清空，旧目标延迟命中不污染新目标层数。逐星者余响等待整组飞行与返回结束，按实际不同命中目标数发射至多五枚，复用原最终伤害包的 35%；不再返回、分裂、连锁或递归生成逐星箭。
- 誓言获层迁入统一命中入口，使用动作 ID 去重；修复无首领节点仍预留首领位置，导致第一只稀有怪漏生成的索引错误。
- 魂弓补入近距离后退和直线穿透；亡军王印自动重召具有每单位一次限制，死亡与重召生成回放事件。
- 共生兽印接入防御后的单次转移，灵兽只承担其剩余生命允许的份额，双方增伤随灵兽存活生效。群炉主脑共用 `SharedLifePool`，按成员变化保留生命百分比，池耗尽后全体死亡，重新部署从新池开始。
- 静海双壁按敌方破盾优先、持续伤害扣血回盾与六秒共享冷却执行，支付与自伤不进入该入口。装备物理抗性进入承伤；敌方持续伤害独立结算抗性、物理护甲和灵障，不继承原击中的格挡/压制结果。界行罗盘只由实际位移技能触发。
- `verify_domain_names.ps1` 接入总门禁，检查 Git 管理及未忽略的新增代码、文本和路径，不扫描生成缓存与二进制内容。天赋路径的小写两位点位序号是几何 ID，不是开发阶段。
- `AilmentState` 替代敌人异常累计值：流血与点燃选择最强有效实例，中毒独立叠加；保留逐步小数伤害，较强实例过期后较弱实例接替。加快持续伤害保持总量，持续阶段动态读取目标抗性、护甲和灵障。转换来源与攻击增伤分开，避免满额转化继续流血及异常二次吃攻击增伤。
- `CombatActionQueue` 统一记录原始动作、完成时间与防御前进攻包，等待整组投射物完成后调度百式回身、攻法回文、法术回响及幻身复制。复制拥有独立动作 ID、零资源支付和防递归标记；新目标防御与当前减益重新计算。修正先分裂再穿透的顺序，返程朝主角当前位置移动。
- 普通单位、灵兽和构装使用独立受击处理；范围击中与危险地面影响范围内单位。灵兽形态、符文连线、自毁重铸已接入；幻身显示角色半透明残影，不再落入炮台绘制分支。
- 九种保留技能分别生成进攻、防御、单位和资源效果，法力保留不能被恢复填满。铁誓战旗按动作获得护体，末旗护符作用于各战旗，原初映照限制其他元素；元素刻印不消耗战斗动作。诅咒按目标维护容量、刷新与过期，标记只保留一个目标。
- `FlaskRack` 按五个槽位分别保存充能、溢流、恢复、品质和附魔；跨资源费用与充能原子扣除，支持瞬时/持续/结束恢复、速度与总量分离及一次回声。充能跨地图节点保留，结束遭遇取消计时效果。药剂作用域不再进入角色全局属性，功能词缀只在来源药瓶生效时消费。删除旧功能药剂状态机、旧瞬时恢复入口、未使用伤害函数和重复转换解析。
- 赤誓、苍誓戒指进入地图装备快照，路线选择、代价与奖励读取同一份状态；赤誓奖励总增 25%、承担代价后流血总增 60% 且不叠加，苍誓延迟奖励翻倍及最终 Boss 生命/伤害总增 25%。新增地图字段可随现有 JSON 保存，不改变旧档默认行为。
- 守护改为固定容量池，消耗完毕或到期即停止吸收，棱光池只承受元素和虚空击中。魔铠与秘盾脉冲实际支付护盾，支付不进入受击或充能中断入口；秘盾脉冲支付一次后生成守护及初始法术击中。
- 玩家异常与诅咒使用独立容器，接入敌方异常资格、持续伤害、防御、冻结/眩晕停顿与感电承伤；药剂真正解除对应异常并建立四秒免疫，药剂回声不再次净化。复生清除旧异常后，同一旧伤害事件不重新附着异常，旧持续伤害脉冲也不继续作用。
- 地面伤害创建时保存进攻快照，逐帧检查敌人是否仍处于区域内，再使用当前防御。炽焰路径、虚蚀领域、裂隙初始击中及后续地面、腐蚀陷阱触发与地面分别结算；重叠同名地面选择完整最强实例，不拼接各元素最高值。烙印与雷暴按自身持续时间和间隔产生实际脉冲。
- 法术点伤恢复到实际点伤单位并按技能范围掷骰，基础暴击采用法术自身数值。附加寒霜、闪电使用点伤和一次伤害效用；附加火焰、精准暴击和疾咏读取所连接辅助的独立等级，删除固定通用增伤近似及错误的主动品质通用增伤。
- 普通投射物沿发射方向做逐步线段碰撞，只有逐星箭继续追踪目标；穿透保持方向，连锁重新瞄准，返程使用当前主角位置。逐星上限测试把目标放入真实射程后仍保留五箭断言。
- `CombatBuffState` 管理同行祝福、战歌、王魂号令和阴阳姿态的对象、期限与范围；祝福不再因旧保留分类而永远跳过。单位独立读取范围内的伤害、速度、抗性和集火目标；姿态切换替换效果，仅徒手时生效。诅咒容量按配置优先级保留，不再固定淘汰最早施加者。
- 普通召唤物增幅、迅捷、扩军、护主以及灵兽凶猛、守护读取辅助自己的等级和品质。护主只转移范围内合法单位可承担的击中伤害，转移不再经过单位防御；灵兽辅助与分痛升华分担比例合并并受上限限制。修复构装增殖和重铸分支的节点 ID 拼写错误。
- 已核对技能的施法与冷却时间统一按每秒二十步换算；保留原来没有重新确认的施放距离。固定构筑审计发现一次无依据的元素棱镜距离改动，已恢复原距离，未用更新基准掩盖它。
- 幻身到期与超限移除取消尚未执行的复演；替身保护选择最近幻身，不能产生献祭、恢复或主角受击收益。普通消失按半秒共享冷却恢复生命/护盾，献祭使用最近实际复演的伤害包与复制比例，作为不再触发击回、偷取或复制的范围结算。命令复演保留每个幻身生成时的辅助伤害比例。
- 复制根据当前位置检查射程，原目标死亡或离开范围后重新选敌；防御和目标减益重新计算。区分复制与普通触发上下文，复制禁止装备击回、偷取和刻印收益，周期法术与普通反击保留合法命中收益。
- 镜雷反制、应答术式、碎盾回震和铠能震爆进入独立反应队列。来源击中完整结算后再执行反应；护盾支付不触发反制，铠能在下一次攻击动作开始时消耗，即使命中失败也不保留，冲击波独立判定。格挡、受创与攻击触发辅助接入真实来源、冷却、费用和防递归；被辅助技能退出手动选择，触发守护仍生成容量池。
- 凋零射线与护盾汲取按四分之一秒脉冲，分段费用保留小数信用，不因每步向上取整重复收费；汲取进入护盾偷取实例。末日咒印维护最多三枚附着、咒印积累、五秒到期/死亡爆炸及最多两目标的一次传播，并占用诅咒容量。
- 周期区域保存施放时的满生命、灵兽存活、生命支付、坠星和复生装备状态；后续脉冲继续读取当前目标防御与减益。专精击中判断不再把持续标签误当持续伤害，实际距离和附近敌人数传入已实现的条件规则。
- `LinkedSupportRules` 合并单位、幻身、姿态、光环、祝福和守护的辅助等级/品质读取。补入誓旗/光环保留费用、祝福延续、姿态增幅、魔铠融合与快速重铸；移除对应旧通用增伤近似。单位持续伤害使用当前祝福抗性和凶猛承伤，元素抗性不再错误减免物理伤害。

## 存档迁移

存档格式为 25，SQLite schema 为 5。旧状态表按时间戳导入正式表，保留原表作恢复副本；重复启动不会覆盖更新存档。在 JSON 反序列化前迁移辅助枚举、辅助 ID、逐颗辅助等级/品质、珠宝和远征字段，再迁移旧领域 ID 和字典键。玩家名字与物品实例 ID 保留原值，旧首领地图实例 ID 在读取边界兼容。

## 验证与边界

`DomainRegressionTests` 包含二十一项转换、生产战斗、飞行/返回、动作隔离、单位复生、共享生命池、防御、誓言、投射物传奇与存档回归。`CombatClosureTests` 包含四十六项机制回归，新增覆盖引导分段支付、末日咒印、反击来源顺序、触发守护、铠能消耗、幻身替身/献祭、装备快照、复制收益隔离及击中专精。完整门禁日志为 `artifacts/continuation-verify.log`，包含解决方案、全量测试、Godot 导入/无界面启动、资产和四份固定种子审计。

完整门禁覆盖 520 项测试、解决方案构建、全部资源检查、Godot 4.7.2 导入与无界面启动，以及四份审计重生成与基准比对。427 份有效代码/文本及全部有效路径纳入领域命名检查；另检查差异空白与 LFS 对象。无界面启动与机器资源检查不代替逐帧、逐技能的实机美术验收。

本轮经济和装备生成审计保持一致。铁壁卫基准把格挡触发连接在重击上；此前仍并行手动使用该技能，修正为仅由格挡触发后，两组胜利数由 98/100、100/100 变为 61/100、95/100，平均耗时变为 60.71、33.89 秒。其余四组仍全部获胜，耗时为 14.19、11.02、12.85、9.98 秒。36 套构筑审计的两组末日咒印清图评分因施法时间修正下降 0.2。保留这些实际差异，没有调整伤害、固定配装或门禁阈值掩盖结果；它们不能作为当前全套构筑平衡已验收的证据。

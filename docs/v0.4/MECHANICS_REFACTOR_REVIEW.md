# 机制修复与领域重构复核

日期：2026-09-05

本轮继续修复已确认设计。**遗留项尚未全部关闭，继续修复后再讨论 v0.5。**

## 已完成的重构与修复

- 代码、文档、脚本、测试、工具和资源引用改为领域名称；修复重命名造成的命名空间冲突、节点坐标编号损坏、百分比格式损坏、音频扩展名误替换、脚本编码错误和悬空客户端标识文件。
- 主角技能统一进入 `ResolveHeroHit` 与 `DamagePacketRules`，移除早期独立纯物理结算、重复类型增伤和仅供测试使用的转换归一函数。装备九条转换边与四类额外伤害进入实际伤害包，按历史类型阶段计算提高，满额转换不残留舍入产生的物理分支。
- 额外伤害适用于对应的原始和转换后元素分支。实际重击对照验证全物理转火后使用火焰抗性；另覆盖多阶段提高、元素额外虚空、过量转换及舍入守恒。
- `ProjectileSimulation` 独立处理飞行位置、穿透、分裂、连锁和返回；去程与返程分别维护命中集合，保存发射时构筑、技能和装备动作状态。返回没有未经设计的统一伤害惩罚，额外连锁读取发射动作状态。
- 合猎箭匣按不同动作攒层，强化动作的全部投射物可以命中主目标，首枚以后总降 60%；换主目标和战斗结束清空，旧目标延迟命中不污染新目标层数。逐星者余响等待整组飞行与返回结束，按实际不同命中目标数发射至多五枚，复用原最终伤害包的 35%；不再返回、分裂、连锁或递归生成逐星箭。
- 誓言获层迁入统一命中入口，使用动作 ID 去重；修复无首领节点仍预留首领位置，导致第一只稀有怪漏生成的索引错误。
- 魂弓补入近距离后退和直线穿透；亡军王印自动重召具有每单位一次限制，死亡与重召生成回放事件。
- 共生兽印接入防御后的单次转移，灵兽只承担其剩余生命允许的份额，双方增伤随灵兽存活生效。群炉主脑共用 `SharedLifePool`，按成员变化保留生命百分比，池耗尽后全体死亡，重新部署从新池开始。
- 静海双壁按敌方破盾优先、持续伤害扣血回盾与六秒共享冷却执行，支付与自伤不进入该入口。装备物理抗性进入承伤；敌方持续伤害独立结算抗性、物理护甲和灵障，不继承原击中的格挡/压制结果。界行罗盘只由实际位移技能触发。
- `verify_domain_names.ps1` 接入总门禁，检查 Git 管理及未忽略的新增代码、文本和路径，不扫描生成缓存与二进制内容。天赋路径的小写两位点位序号是几何 ID，不是开发阶段。
- `AilmentState` 替代敌人异常累计值：流血与点燃选择最强有效实例，中毒独立叠加；保留逐步小数伤害，较强实例过期后较弱实例接替。加快持续伤害保持总量，持续阶段动态读取目标抗性、护甲和灵障。转换来源与攻击增伤分开，避免满额转化继续流血及异常二次吃攻击增伤。
- `CombatActionQueue` 统一记录原始动作、完成时间与防御前进攻包，等待整组投射物完成后调度百式回身、攻法回文、法术回响及幻身复制。复制拥有独立动作 ID、零资源支付和防递归标记；新目标防御与当前减益重新计算。修正先分裂再穿透的顺序，返程朝主角当前位置移动。
- 普通单位、灵兽和构装使用独立受击处理；范围击中与危险地面影响范围内单位。灵兽形态、符文连线、自毁重铸已接入；幻身显示角色半透明残影，不再落入炮台绘制分支。
- 九种保留技能分别生成进攻、防御、单位和资源效果，法力保留不能被恢复填满。铁誓战旗按动作获得护体，末旗护符作用于各战旗，原初映照限制其他元素；元素刻印不消耗战斗动作。诅咒按目标维护容量、刷新与过期，标记只保留一个目标。
- `FlaskRack` 按五个槽位分别保存充能、溢流、恢复、品质和附魔；跨资源费用与充能原子扣除，支持瞬时/持续/结束恢复、速度与总量分离及一次回声。充能跨地图节点保留，结束遭遇取消计时效果。药剂作用域不再进入角色全局属性，功能词缀只在来源药瓶生效时消费。删除旧功能药剂状态机、旧瞬时恢复入口、未使用伤害函数和重复转换解析。
- 赤誓、苍誓戒指进入地图装备快照，路线选择、代价与奖励读取同一份状态；赤誓奖励总增 25%、承担代价后流血总增 60% 且不叠加，苍誓延迟奖励翻倍及最终 Boss 生命/伤害总增 25%。新增地图字段可随现有 JSON 保存，不改变旧档默认行为。

## 存档迁移

存档格式为 25，SQLite schema 为 5。旧状态表按时间戳导入正式表，保留原表作恢复副本；重复启动不会覆盖更新存档。在 JSON 反序列化前迁移辅助枚举、辅助 ID、逐颗辅助等级/品质、珠宝和远征字段，再迁移旧领域 ID 和字典键。玩家名字与物品实例 ID 保留原值，旧首领地图实例 ID 在读取边界兼容。

## 验证与边界

`DomainRegressionTests` 包含二十一项转换、生产战斗、飞行/返回、动作隔离、单位复生、共享生命池、防御、誓言、投射物传奇与存档回归。`CombatClosureTests` 再增加十六项异常、药剂隔离与原子支付、保留法力、复制、诅咒、地图快照与三种灵兽形态回归。完整门禁日志为 `artifacts/continuation-verify.log`，包含解决方案、全量测试、Godot 导入/无界面启动、资产和四份固定种子审计。

完整门禁验证 490/490 测试、解决方案构建、全部资源检查、Godot 4.7.2 导入与无界面启动，以及四份审计重生成与基准比对。416 份有效代码/文本及全部有效路径通过领域命名检查；差异空白与 LFS 对象检查通过。无界面启动与机器资源检查不代替逐帧、逐技能的实机美术验收。

本轮经济、36 套构筑和装备生成审计与此前重构基准完全一致。异常、药剂及光环结算修正后，血战士开荒组为 100/100；其余五组依次为 100/100、98/100、100/100、100/100、100/100。六组平均节点耗时为 14.19、11.02、17.42、16.54、12.85、9.98 秒。战斗报告按实际结果更新，没有调整门禁阈值或隐藏失败样本。

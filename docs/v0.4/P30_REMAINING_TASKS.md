# P30 剩余任务与关闭顺序

> 更新日期：2026-09-01
> 状态：P30 核心战斗公式、装备词缀、1475 节点主树、十八升华、珠宝与美德/恶德已进入运行时；仅保留以下三项

## 1. 技能基础表

- 为全部主动与辅助技能固化 1～21 级基础伤害、伤害效用、攻击/施法频率、基础暴击、资源消耗、标签与连接兼容。
- 补齐徒手、盾击、召唤物、构装体、陷阱、幻身等单位基础表，并让实时、离线与 48 小时模拟读取同一份数据。
- 清除旧技能、P17 与 P24 间的重复常量；完成后用固定种子公式测试作为门禁。

## 2. 36 套构筑验证

- 十八升华各维护一套 70 级开荒构筑和一套 100 级终局构筑。
- 每套固定主天赋、专精、升华、装备、珠宝、技能连接、药剂与正式 AI；覆盖剧情、T1、T10、T16、T20 及攻坚 Boss。
- 输出 DPS、清图效率、有效生命、恢复、失败原因与玩法收益；只以该审计微调数值，不重开已经确认的节点身份。

## 3. UI、美术与性能验收

- 逐页检查标准窗、大窗、小窗及 80%/90%/100% 字体缩放，验证裁切、滚动、拖放、悬浮、Alt 详情与像素对齐。
- 完成天赋、升华、珠宝、技能和装备的最终像素反馈与战斗可读性。
- 验证 60 FPS 交互、周期性卡顿、托盘/退出、实时/离线一致性和 Godot 无错误启动；通过后关闭 P30。

以上三项严格按顺序推进。它们是 P30 唯一剩余工作，不把已完成的公式、主树、十八升华、珠宝、美德/恶德或装备词缀重复列为待实现。

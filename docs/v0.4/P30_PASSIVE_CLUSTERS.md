# P30 主天赋簇逐类数值规格

> 状态：逐类型确认中（剑类、斧类、锤类、匕首、弓类、法杖、符刃已确认）
> 更新日期：2026-08-31
> 所属阶段：P30

## 1. 共用结构

- 每种武器拥有两个中型簇（各 4 小点、1 显著、1 专精）和一个大型簇（8 小点、2 显著、1 专精）。
- 中型簇使用双路汇合；任选一路即可到显著。大型簇使用单入口双分支环状结构；任选一个显著即可解锁专精。
- 同类型的三个专精节点共享专精池；同一角色不能重复选择相同专精效果。
- 属性路径节点不计入主题小点；伤害小点以 `16%～20% increased` 或等效复合收益为基础，允许按武器身份提高攻速、格挡、暴击与异常价值。
- 所有节点稳定 ID、连接边和最终底图预留位置必须完全一致；未确认类型不得提前生成占位数值。

## 2. 剑类天赋簇（已确认）

剑类定位：命中、暴击、攻速、格挡反击、闪电转化与异常。

### 2.1 精准剑锋

入口属性：`+10 灵巧`。连接为入口后分成两条各 2 小点的路线，在显著处汇合，再连接专精。

| 节点 | 效果 |
| --- | --- |
| 磨锋 | 剑类攻击伤害提高 18% |
| 寻隙 | 剑类攻击暴击率提高 35% |
| 定准 | 剑类攻击命中 +180，剑类攻击伤害提高 12% |
| 快腕 | 剑类攻击速度提高 6% |
| 精确处刑·显著 | 剑类攻击伤害提高 35%，暴击率提高 20%，命中 +100 |

### 2.2 回风剑势

入口属性：`+10 体魄、+10 灵巧`。同样使用双路汇合结构。

| 节点 | 效果 |
| --- | --- |
| 疾腕 | 剑类攻击速度提高 6% |
| 顺斩 | 剑类攻击伤害提高 18% |
| 侧锋 | 持剑时攻击格挡率 +5% |
| 长锋 | 剑类近战打击距离 +1，范围效果提高 20% |
| 回风架势·显著 | 剑类攻击速度提高 10%，持剑时攻击格挡率 +5% |

### 2.3 百相剑庭

只有一个 `+10 灵巧` 入口，随后分为物理暴击与元素异常两路；两路顶部相连形成环，断岳之锋或流光之锋任意一个均可解锁专精。

单一入口 ────────────────┤                                      ├─ 顶部连接

                                      断岳/流光 ─ 剑类专精

| 节点 | 效果 |

| 贯身 | 剑类攻击伤害提高 18% |
| 沉腕 | 剑类攻击速度提高 6% |
| 元素淬锋 | 剑类元素伤害提高 20% |

| 流光之锋·显著 | 剑类攻击伤害提高 35%，攻击速度提高 7%，+25 灵巧 |

`剑类攻击伤害提高`只强化击中；异常使用单独的“剑类攻击造成的异常伤害”修正。

### 2.4 剑类专精池

1. **无锋**：剑类攻击暴击伤害倍率 `+80%`；剑类攻击暴击率降低 `100%`。降低与其他暴击率提高/降低进入同一加法池，不是 `100% less`。
2. **夺隙剑理**：剑类攻击暴击率幸运；剑类暴击造成 `20%` 更少伤害。
3. **延锋术**：剑类近战打击距离 `+2`、范围效果提高 `40%`；剑类投射物最大距离提高 `25%`。
4. **格反**：持剑时攻击格挡率 `+8%`；成功格挡后 2 秒内下一次剑类击中造成 `50%` 更多伤害，触发冷却 1 秒。
5. **霹雳淬锋**：剑类物理伤害的 `40%` 转化为闪电伤害。
6. **伤痕剑术**：剑类攻击造成的流血、中毒和点燃造成 `20%` 更多伤害；物理伤害有 `30%` 概率流血，物理或虚空伤害有 `30%` 概率中毒，火焰伤害有 `30%` 概率点燃，闪电伤害有 `30%` 概率感电。概率与其他来源相加并受 `100%` 上限限制。
7. **连斩**：连续命中同一目标获得锋势，最多 5 层；每层使剑类攻击速度总增 `7%`，五层合计为一个 `35% more` 乘区。未命中、切换目标或 1 秒内没有剑类命中时失去全部层数。

剑类武器标签提高进入首阶段加法池；物理与元素提高进入对应转化阶段；法术只有通过明确法武继承才能引用剑类规则。

## 3. 斧类天赋簇（已确认）

斧类定位：高单次物理、暴击流血、破甲、低生命收益和可跳过 Boss 阶段的处决。

### 3.1 开山重斧

入口属性 `+10 体魄`；双路各 2 小点后汇入显著与专精。

| 节点 | 效果 |
| --- | --- |
| 劈骨 | 斧类物理伤害提高 20% |
| 破胄 | 斧类击中有 35% 概率施加 1 层破甲，破甲持续时间提高 20% |
| 沉肩 | 斧类攻击伤害提高 25%，攻击速度降低 3% |
| 震颅 | 斧类击中造成眩晕的概率提高 30%，斧类攻击伤害提高 12% |
| 开山之力·显著 | 斧类物理伤害提高 55%，斧类击中忽略 20% 护甲，并有 50% 概率额外施加 1 层破甲 |

额外破甲层要求本次击中先成功施加破甲，不能在没有破甲资格时单独生成。

| 节点 | 效果 |
| --- | --- |

| 猎伤 | 对流血敌人的斧类攻击伤害提高 24% |
| 趁势 | 对流血敌人的斧类攻击速度提高 7% |

伤害加快保持流血总伤害不变，以更短持续时间完成。

单一 `+10 体魄` 入口，分为重击/暴击流血与异常/低生命两路；顶部相连，断首刑斧或行刑者任一显著可解锁专精。

| 节点 | 效果 |

| 巨刃 | 斧类物理伤害提高 20% |
| 暴断 | 斧类攻击暴击伤害倍率 +25%，物理伤害提高 12% |
| 负重 | 斧类攻击伤害提高 30%，攻击速度降低 4% |
| 震地 | 斧类范围效果提高 25%，斧类攻击伤害提高 12% |

| 血锋兼修 | 斧类攻击伤害提高 12%，斧类攻击造成的异常伤害提高 20% |

| 行刑者·显著 | 对低生命敌人的斧类攻击伤害提高 60%；斧类攻击伤害上界提高 15%、下界降低 30% |

伤害上下界在武器及全局附加伤害汇总后、随机伤害掷点前修改：下界乘 `0.70`、上界乘 `1.15`，再沿用同一次掷点比例进入转化和异常基础。低生命定义为不高于 `50%`。

### 3.4 斧类专精池

1. **绝对蛮力**：斧类攻击无法暴击；斧类物理伤害造成 `60%` 更多伤害；斧类攻击速度总降 `15%`。
2. **蓄势断山**：1 秒没有使用斧类攻击时获得蓄势；下一次斧类击中造成 `120%` 更多伤害并消耗，消耗后至少 1 秒才能重新获得。
3. **血瀑**：最多 3 层斧类流血同时造成伤害，每层为普通流血的 `65%`；斧类击中造成 `20%` 更少伤害。
4. **终结刑线**：斧类击中处决生命不高于 `20%` 的敌人；对生命高于 `20%` 的敌人造成 `10%` 更少伤害。处决可以跳过 Boss 的后续强制阶段，直接视为完整击杀，正常结算全部阶段完成状态、掉落、碎片和任务奖励。
5. **碎岭**：斧类击中必定施加 1 层破甲，破甲上限 +3；对达到破甲上限的敌人，斧类击中造成 `30%` 更多伤害。
6. **横扫战场**：斧类近战距离 +2、范围效果提高 `60%`；范围内至少有 3 个敌人时，斧类攻击造成 `30%` 更多伤害，无单体负面。
7. **震魂重击**：斧类击中的眩晕概率和持续时间总增 `100%`；对被眩晕敌人的斧类攻击造成 `25%` 更多伤害。

Boss 被终结刑线处决时不得进入已跳过阶段、生成阶段增援或重复触发阶段奖励；战报必须记录被处决时的生命比例和跳过阶段。

## 4. 锤类天赋簇（已确认）

锤类定位：低频重击、眩晕、破甲、范围震波，以及物理与冰霜转化两条构筑路线。锤类规则只作用于攻击；法术必须通过明确的法武继承规则才能引用。

### 4.1 碎甲震颅

入口属性 `+10 体魄`；双路各 2 小点后汇入显著与专精。

| 节点 | 效果 |
| --- | --- |
| 碎骨 | 锤类物理伤害提高 20% |
| 破胄 | 锤类击中有 40% 概率施加 1 层破甲，破甲持续时间提高 25% |
| 震颅 | 锤类击中造成眩晕的概率提高 40%，锤类攻击伤害提高 12% |
| 沉铁 | 锤类攻击伤害提高 25%，攻击速度降低 3% |
| 破城重锤·显著 | 锤类物理伤害提高 55%，攻击速度降低 5%；锤类击中无视目标 20% 护甲，并必定施加 1 层破甲 |

### 4.2 地鸣回响

入口属性 `+10 体魄`；双路汇合。

| 节点 | 效果 |
| --- | --- |
| 扩震 | 锤类范围效果提高 30% |

地鸣对每次锤类攻击最多触发一次，默认不能命中触发敌人；继承原攻击的伤害类型、转化、暴击结果和异常资格。震波不是一次新的技能使用，不能再次触发地鸣或其他“使用攻击”效果。

单一 `+10 体魄` 入口，分为物理重击与冰霜冻结两路；顶部相连，天坠重锤或霜鸣重锤任一显著可解锁专精。

                         └─ 霜铸 ─ 寒震 ─ 霜鸣重锤 ─ 冰扩 ─ 迅震 ─┘

| 节点 | 效果 |

### 4.4 锤类专精池

1. **万钧一击**：锤类击中伤害总增 `100%`，锤类攻击速度总降 `40%`；锤类攻击造成的伤害型异常总降 `30%`。
2. **地鸣归心**：锤类震波可以命中触发该震波的敌人，但震波伤害总降 `30%`；每道震波有 `30%` 概率在同一位置额外触发一次震波。额外震波沿用原震波伤害包和命中范围，且不能再次触发额外震波。
3. **粉碎法则**：锤类击中必定施加 2 层破甲，破甲上限 +4；目标达到破甲上限时，物理抗性额外降低 `15%`。
4. **震慑**：对未被眩晕的敌人，锤类击中造成眩晕的概率总增 `100%`；对已被眩晕的敌人，锤类攻击造成 `30%` 更多伤害。
5. **冰霜锻锤**：锤类物理伤害的 `50%` 转化为冰霜伤害；锤类攻击造成的冻结最低持续时间为 `0.3` 秒；锤类攻击不能造成流血或中毒。
6. **横扫震域**：锤类近战距离 +2；锤类攻击、震波和震击的范围效果提高 `80%`。
7. **三击定音**：每第三次锤类攻击命中后，延迟 0.4 秒产生一道二次震击；二次震击使用原攻击防御前伤害包的 `100%`，是可以命中原目标的独立范围攻击击中，但不能触发震波、重复攻击或另一次三击定音。

冰霜锻锤与霜鸣重锤合计提供 `90%` 物理转冰；若其他来源令同阶段转化总和超过 `100%`，继续遵守全局转化归一化规则。地鸣归心的额外震波只进行一次独立概率判定，不能形成递归链；横扫震域同时影响地鸣震波与三击定音震击的半径。

6. **交错护持**：使用符刃攻击后 2 秒内法术压制率 +20%；自行施放法术后 2 秒内攻击格挡率 +15%，两种状态可以同时存在。
7. **天地刻爆**：六重刻阵达到 6 层时，下一次符刃攻击或自行施放法术消耗全部层数，在目标位置产生使用触发技能防御前伤害包 `200%` 的独立范围击中。爆炸继承伤害类型历史、暴击结果和异常资格，但不是攻击或法术，不能触发、重复或再次生成刻印爆炸。

# v0.2 核心战斗与构筑扩充规格

> 状态：已确认
> 更新日期：2026-08-28
> 产品版本：`v0.2`
> 实施阶段：P16～P22

## 1. 版本定位

v0.2 不增加新的大型独立玩法循环，而是在首个可玩 Demo 的主线、异界、城镇、装备、技能和实时空间战斗基础上，补齐怪物威胁、技能组合、装备词缀、掉落经济、美术动画与铁誓者三套升华，使现有流程具备可长期重复游玩的构筑深度。

以下内容整体延期到 v0.3，不进入 v0.2 的数据、UI、掉落或验收范围：

- 亡旗战场
- 沉金港
- 无光矿脉

v0.2 仍只完整开放铁誓者主角，不增加第二主角职业、永久死亡挑战、第三远征队、音频、手柄、Steam 或联网功能。异界继续使用现有裂渊追猎、命能花园、赤誓/苍誓祭坛和灰烬天垒作为构筑验证环境。

## 3. 难度与等级曲线

### 3.1 等级映射

怪物难度从剧情第一章开始调整，不把剧情作为无威胁教程，也不等进入异界后才突然提高强度。

| 内容 | 怪物等级 |
|---|---:|
| 第一章 | 1～12 |
| 第二章 | 13～27 |
| 第三章 | 28～43 |
| 第四章 | 44～57 |
| 第五章 | 58～69 |
| 异界 T1 | 70 |
| 异界 T2～T20 | 按固定表在 70～100 间递增，T20 为 100；完整表见 `P16_SPECIFICATION.md` |

地图阶级与角色等级不要求一一相等。角色 100 级突破和 101～120 级成长规则保持不变；高阶地图通过怪物等级、地图词缀、稀有怪组合和特殊规则共同形成压力。

### 3.2 剧情难度职责

- 第一章教授攻击范围、移动、技能预警和药剂，不使用无预兆秒杀。
- 第二章开始要求处理火焰、冰霜和闪电抗性，并出现具有后排能力的怪群。
- 第三章开始正式引入流血、点燃、冰缓、感电、压制和持续地面。
- 第四章引入成组魔法怪、支援型怪物、尸体利用与复合伤害。
- 第五章引入三到四词缀稀有怪和接近异界的抗性、生存与伤害检查。
- 通关剧情的正常角色应处于进入 70 级 T1 的装备和抗性准备状态。

### 3.3 异界难度职责

- T1～T5 已经具有 PoE 式构筑压力；只有伤害而没有基础防御的角色会失败。
- T6～T10 检查抗性、回复、控制处理、单体伤害和清怪覆盖范围。
- T11～T16 要求完整攻防循环，危险地图词缀必须进入地图筛选与停止方针。
- T17～T20 要求成型升华、合理加工装备、完整孔组和针对性防御。
- 标准同阶构筑对普通怪的预期为 1～3 次有效攻击，魔法怪为 3～8 秒，稀有怪为 10～25 秒，地图 Boss 为 45～120 秒。

高压不等于无预兆秒杀。危险攻击必须提供可观察的起手、范围或战斗报告原因；自动战斗 AI 必须能根据已知敌人和地图危险作出撤退、保持距离或切换合法目标等决策。

## 4. P16：怪物体系与战斗平衡

P16 的完整实现与验收规则见 [`P16_SPECIFICATION.md`](P16_SPECIFICATION.md)。除怪物与难度外，P16 同时完成文档版本化、地图 Tier/MonsterLevel 拆分、批量出售/分解、双排序和单按钮过滤器编辑器。

### 4.1 数据模型

将怪物从单一属性模板扩展为数据驱动定义，至少包含：

- 家族、战斗职责、稀有度和怪物等级
- 生命、护甲、闪避、能量护盾、法术压制和五类抗性
- 攻击伤害类型、攻击/施法速度、移动速度、攻击范围和资源
- 主动技能、冷却、施法距离、目标选择、移动策略和危险预警
- 尸体、召唤物、光环、持续地面和死亡效果等行为能力
- 基础经验、掉落预算、魔法/稀有词缀池和地图出现权重

### 4.2 内容规模

- 制作 6 个怪物家族，每族 8 种非 Boss 怪物，共 48 种。
- 每个家族至少覆盖近战前排、远程、施法、冲锋/突进、控制和支援职责。
- 实现普通、魔法、稀有、Boss 四档稀有度。
- 魔法怪拥有 1～2 个词缀；稀有怪拥有 3～4 个词缀。
- 实现 18 个怪物词缀，覆盖生存、伤害、速度、光环、召唤、尸体和死亡效果，但禁止生成相互矛盾或无法被当前构筑处理的组合。
- 节点中的全部怪物共同进入战场，并根据职责形成前后排；不退回两边站定的一对一交换伤害。

### 4.3 平衡方法

不直接复制 PoE 的绝对生命和伤害。建立剧情章节、T1、T5、T10、T16、T20 六组固定基准角色，使用确定性战斗种子和批量模拟调整：

- 清图时间、Boss 时间、角色死亡率和药剂消耗
- 近战、远程、范围、连锁和单体技能的收益差距
- 低抗性、低护甲、低压制、低回复等缺陷的可观察后果
- 普通、魔法、稀有和 Boss 的经验及掉落预算

P16 验收时，48 种怪物必须真实进入剧情和地图池，六组基准能够重复模拟，且剧情至 T20 不存在固定时间推进或忽略移速、范围与怪群数量的退化路径。

## 5. P17：技能石底层与内容扩充

### 5.1 三层技能描述

技能系统拆分为三个独立层次：

1. **展示标签**：攻击、法术、近战、打击、猛击、投射物、范围、持续、引导、移动、战吼、光环、护卫、物理、火焰、冰霜、闪电、虚空等。
2. **执行能力**：能否命中、暴击、连锁、穿透、分裂、重复、造成持续伤害、产生投射物、保留资源或施加异常。
3. **辅助条件**：必须能力、任一能力、排除能力、支持对象和效果组件，不再用一个重合标签直接判断兼容。

技能信息悬浮必须分别显示标签、技能行为、可用辅助和不兼容原因。现有“同名技能共享冷却”和逐技能攻击目标规则保持不变。

### 5.2 内容范围

- 累计 30 个主动技能和 48 个辅助技能。
- 约 70% 内容服务铁誓者的流血、格挡、反击、猛击、击晕、破甲、战吼和近战范围构筑。
- 约 30% 为通用元素、法术、投射物、移动、防御和光环能力。
- v0.2 不加入召唤物、陷阱、地雷和图腾，它们随未来职业或专属玩法开发。
- 主动技能由组合式效果组件执行，禁止继续为每颗技能在战斗循环中增加一整套不可复用的分支。

P17 验收时，所有技能可以升级、装入孔组、接受合法辅助、被自动战斗 AI 使用，并在战斗报告中说明命中、伤害、异常和辅助修正来源。

详细定稿见 [P17 技能石底层与内容规格](P17_SPECIFICATION.md)。

## 6. P18：铁誓者三套升华

### 6.1 升华方向

- **血征者**：流血、生命消耗、低生命增伤、击杀回复和持续伤害扩散。
- **壁垒使**：盾牌、格挡、护甲、反击、防御转化和保护性光环。
- **破阵者**：双手武器、猛击、击晕、破甲、战吼和范围清场。

每套升华拥有六个方向，每个方向由 1 个强化节点连接 1 个改变玩法的核心节点，共 12 点。角色最多获得 8 点，因此最多完成四个方向；三套升华不能混点，也不得退化为单纯数值高低的选择。

### 6.2 构筑验收

每套升华至少维护两套自动化基准构筑，共六套：一套偏易获得装备，一套偏终局加工装备。v0.2 不增加新最终 Boss；六套构筑用于验证重新平衡后的剧情、T1、T10、T16、T20和现有灰烬天垒。

P18 同批加入初始法力药剂、生命/法力药剂击杀充能与自动使用、非法术攻击基础耗蓝降低20%、默认法力恢复从最大法力5%/秒提高到6%/秒。完整节点、连接、数值和交互见 [P18 铁誓者三升华与资源循环规格](P18_SPECIFICATION.md)。

## 7. P19：装备底材与词缀库

### 7.1 PoE 数据参考原则

第一版直接采用选定 Path of Building Community 快照中的 PoE 基础底材数值与常规基础显式词缀数据，包括档位、数值范围、物品等级门槛、权重、词缀组和适用标签；不在 P19 中重新缩放。混沌体系映射为虚空体系，并按精神词缀的档位、槽位和权重镜像增加能量属性词缀。弓、法杖、召唤等本作尚未支持的对象和死属性过滤掉。

离线转换结果作为版本控制内的本地 JSON；游戏运行不依赖 Path of Building、外部数据库或网络。稳定 ID 与玩家可见名称使用本作术语，源 ID 和文件哈希仅用于数据溯源。

### 7.2 内容规模

- 装备底材从约 40 种扩展到约 80 种。
- 加入单手武器和盾牌，保证壁垒使拥有完整装备路径。
- 暂不加入以未来职业为主要使用者的弓、法杖和召唤专属底材。
- 建立约 90 个词缀族、约 400 条分级词缀记录；常规词缀族通常具有 6～10 个等级档。
- 支持复合词缀、局部/全局属性、底材标签权重、物品等级门槛、互斥组和制作来源。
- 工坊附魔、金属制作、自然掉落和传奇生成读取同一套合法性规则。
- 游戏内公开可出现词缀、数值范围、标签、权重、物品等级和制作来源。

每种底材拥有独立背包图标；世界角色外观继续只表现武器、副手、头部和胸甲等主要装备，不要求戒指、腰带、手套和鞋子逐件改变纸娃娃。

装备悬浮显示实际值、范围、T级、物品等级门槛和来源；不同T级在同一字体色相内使用轻微亮度梯度，并始终保留文字T级。完整规则见 [P19 装备底材与基础词缀库规格](P19_SPECIFICATION.md)。

## 8. P20：掉落公式与经济

### 8.1 计算顺序

每只怪物死亡时使用确定性随机源计算掉落预算，节点结束时批量实例化和展示，避免逐怪创建 UI、数据库写入或资源加载造成战斗卡顿。

```text
怪物掉落预算 =
基础预算(怪物等级与职责)
× 怪物稀有度系数
× 地图数量系数
× 地图机制系数
× 队伍难度系数
```

预算依次分配到装备、金属、地图、技能石、Boss 碎片和特殊物品。装备按照以下顺序生成：

```text
物品类别 → 合法底材及权重 → 物品等级 → 稀有度
→ 词缀数量 → 合法词缀族及权重 → 词缀等级 → 数值
```

权重选择统一使用 `候选权重 / 全部合法候选权重之和`。物品数量和物品稀有度分别计算，不使用无法追踪来源的固定稀有装备概率。

### 8.2 掉落目标

- 移除当前每图固定 10% 传奇掉率。
- 常规传奇的长期目标为约每 20～40 张同阶地图出现一件。
- 高阶传奇主要进入指定 Boss 或高阶特殊掉落池，并保留重复挑战后的定向兑换保底。
- 同阶地图的长期基础续航期望约为每图 1.08 张；允许短期波动，但不能让正常异界挂机频繁断档。
- 内部完整计算所有掉落，但只实例化需要展示或入库的物品；低价值物根据唯一掉落规则自动出售、分解或忽略。
- 金属自动进入金属仓并堆叠，不占普通背包格。
- 掉落规则支持类别、稀有度、物品等级、底材、完整词缀和估算价值，继续禁止战斗 AI 读取尚未掉落的随机结果。

P20 必须提供批量蒙特卡洛审计，至少报告剧情、T1、T10、T16、T20与Boss的每小时装备、金币、金属、地图和传奇产出分布；只验证单次好运样本不视为通过。完整实现口径与审计快照见 [P20 掉落公式与经济规格](P20_SPECIFICATION.md) 和 [P20 经济蒙特卡洛审计](P20_ECONOMY_AUDIT.md)。

## 9. P21：像素美术与动画扩充

美术在 P16～P20 的内容 ID 和资产清单稳定后统一生成并接入，继续采用适合任务栏小窗的低密度、强轮廓像素风。

- 为 30 个主动技能和 48 个辅助技能制作独立图标。
- 为约 80 种装备底材制作独立图标，统一透明边距、锚点和格内居中规则。
- 制作至少 16 套轮廓明显不同的怪物主体，通过武器、部件、色板和动作组合支撑 48 种怪物；不同类型不能只靠改名区分。
- 主角、主要佣兵和主要怪物制作四方向待机、移动、攻击/施法、受击和死亡动作。
- 补充猛击、投射物、连锁、穿透、爆炸、持续地面、护盾、格挡、流血和元素异常等可辨识特效。
- 传奇装备可以增加额外轮廓、光效或特殊动作；普通底材不要求全部改变战场角色外观。
- 所有图集必须通过自动边界检查和人工预览，禁止再次出现相邻帧或相邻角色被裁入的问题。

## 10. P22：整合、平衡与 v0.2 封版

P22 不新增主要系统，只修复跨系统问题并形成可验证发布包：

- 完成“新角色→五章剧情→T1→T16→百级突破→T20→灰烬天垒”的全流程回归。
- 使用六套升华基准构筑执行难度、清图效率、死亡原因和经济回报对比。
- 验证前台实时战斗 60 FPS、后台模拟、UI 操作、节点结算和自动保存没有固定周期卡顿。
- 执行两小时长稳、48 小时离线、字体 80%～150%、窗口尺寸矩阵和托盘恢复测试。
- 只承诺迁移正式 `v0.1.0-demo` 存档；测试期中间格式允许作废，不建立无限历史迁移链。
- 完成 Debug/Release 编译、`dotnet test`、Godot 导入与启动检查及 Windows 便携包。
- 发布版本标记为 `v0.2.0`；亡旗战场、沉金港和无光矿脉不得以未完成入口出现在正式 UI。

## 11. 阶段依赖与交付规则

开发顺序固定为：

```text
P16 怪物与难度
  → P17 技能底层与技能石
  → P18 三套升华
  → P19 底材与词缀
  → P20 掉落与经济
  → P21 美术与动画
  → P22 整合封版
```

该顺序用于避免先制作美术后改变内容 ID，也避免在技能行为尚未数据化时编写升华和大量辅助技能。

每个 P 都必须完成对应代码、静态数据、测试和文档更新，执行项目约定的本地验证后直接提交并推送。用户在已推送构建上体验；发现问题时使用后续修复提交，不长期改写已推送历史。

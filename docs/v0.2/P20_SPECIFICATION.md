# P20 掉落公式与经济规格

## 1. 完成范围

P20 把剧情与异界统一到“逐怪记账、节点末批量结算”的确定性掉落链路。战斗过程中不创建物品 UI、不写存档；节点结束后才生成结算批次并让过滤器处理。失败节点保留已经击杀敌人的击杀掉落与经验，但不发地图、记忆灰烬、监守印记等完成奖励。

## 2. 掉落预算

每个死亡敌人独立贡献整数预算，基础稀有度系数固定为：

| 怪物稀有度 | 预算系数 |
|---|---:|
| 普通 | 100 |
| 魔法 | 250 |
| 稀有 | 800 |
| Boss | 3,000 |

预算再读取敌人职责威胁、怪物等级、地图危险度、地图数量和收益路线。全部倍率使用万分比整数计算，抽样使用可复现的确定性随机源；不得使用玩家战力、死亡次数或仓库状态暗中修正掉落。

节点预算分别投向装备、金币、金属、技能石与地图。路线倾向固定为：

- 安全路线：装备与金币；
- 裂渊路线：技能石、Boss 碎片进度、危险/高阶金属；
- 命能花园：制作底材、金属与命能材料。

产出数量使用带随机余数的预算抽样，不把小数期望直接取整，因此同配置短期有波动、长期收敛。

## 3. 装备与物品等级

- 普通来源物品等级等于怪物等级；稀有来源 `+1`；Boss 来源 `+2`，最高 120。
- 普通怪基础装备稀有度为基础 68%、魔法 25%、稀有 7%；魔法、稀有与 Boss 来源以及地图危险度可提高稀有档。
- 底材从不高于物品等级需求的合法 P19 底材池按等级接近度加权抽取，词缀继续使用 P19 合法性和权重。
- 连接数由装备生成器独立抽取，不读取地图数量加成。
- 不提供智能掉落，不按当前职业、已装备物品或技能方案修正底材和词缀。

## 4. 地图、传奇和 Boss 保底

- 同阶地图基础长期续航为每图 1.08 张；掉落层级以同阶和低一阶为主，少量高一阶与高两阶，且不超过当前解锁上限。
- 普通传奇基准直掉率为 3.33%，约 1/30 节点；Boss 专属池基准为 8%。练习挑战不发任何奖励。
- 深渊监守者与灰烬天垒读取独立的 Boss 传奇池；普通传奇池排除这些专属项。
- Boss 监守印记可累计 12 枚，在城镇从全部非神话传奇中指定一件兑换。仓库已满时不会先扣印记。
- 地图数量加成影响装备、金币、金属、技能石、地图、完成材料、传奇概率以及固定监守者/灰烬天垒 Boss 碎片进度。固定碎片使用随机余数处理，数量加成不是每次都向上取整。

## 5. 金属、金币与价值

金属掉落读取 P9 完整金属目录与原始掉落权重，并由路线偏置基础、进阶、高阶和危险档。金属直接进入金属仓，不占普通装备格。

每件装备公开显示估算价值和出售金币。估值读取物品等级、底材需求、稀有度、词缀T级与数值、连接数、制作底材标记和神话状态；出售价格为公开估值的 5%，不再使用按稀有度固定售价。估值只用于显示、过滤与交易，不反馈战斗 AI。

## 6. 过滤与批量结算

过滤器新增估值下限、估值上限和“忽略”处理。处理顺序仍为从上到下首次匹配。以下物品由系统强制保留，用户规则不能覆盖：

- 已锁定物品；
- 任务/关键物品；
- 首次获得的底材或传奇；
- 五连与六连装备。

节点结束后一次性处理全部装备：保留项入仓，出售项换算金币，分解项产生铁屑，忽略项不产生资源。远征背包只展示最近一次结算中实际保留的最多 20 件显著物品，不再逐击杀刷新 UI 或存档。

未获得过的技能石在通用掉落池中权重为已获得技能石的 3 倍；一旦获得即恢复正常权重。该规则只读取收藏状态，不读取当前战斗需要。

## 7. 验收

- `P20EconomyAudit` 必须可使用固定种子对剧情、T1、T10、T16、T20和Boss各执行至少 100,000 次抽样。
- 审计同时报告节点均值、装备 P10/P50/P90 和按 90 秒/节点折算的小时产出。
- 自动测试覆盖预算常量、地图续航、传奇率、数量加成固定碎片、估值过滤、系统保护与指定传奇兑换。
- 审计快照见 [P20 经济蒙特卡洛审计](P20_ECONOMY_AUDIT.md)，可通过 `dotnet run --project tools/P20Audit/P20Audit.csproj -- 100000` 复现。

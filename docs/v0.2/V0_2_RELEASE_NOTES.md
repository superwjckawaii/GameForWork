# GameForWork v0.2.0 版本说明

`v0.2.0` 是首个覆盖完整五章剧情与 T1～T20 异界循环的可玩候选版本。

## 主要内容

- 五章主线、T1～T20 地图、百级突破与三阶段灰烬天垒。
- 血征者、壁垒使、破阵者三套升华及六套固定基准构筑。
- 约 1200 节点角色天赋、升华天赋、约 360 节点地图天赋与珠宝系统。
- 30 种主动技能、48 种辅助技能、装备底材/词缀、传奇装备、掉落过滤器及金属打造。
- 七座城区建筑、佣兵远征、48 小时离线结算、三存档槽和托盘挂机。
- 正式像素角色/怪物动作、战斗特效、技能/装备图标、天赋底图、像素 UI 和应用图标。
- 高阶装备底材现在拥有更精制的金属边、高光和能量点缀，格内尺寸与稳定 ID 保持不变。
- 标题栏新增统一信息与指引入口，完整旅程说明和词缀库集中在同一信息页。
- 主天赋、升华与异界天赋改为全页底层画布，固定 HUD 不再被拖曳、缩放或画布边框遮挡。

## 存档与运行

- 需要 Windows 10/11 x64。
- 解压后运行 `GameForWork.exe`；不要直接从 ZIP 内运行。
- 存档、设置和日志位于 `%LOCALAPPDATA%\Godot\app_userdata\GameForWork`，更新游戏包不会覆盖该目录。
- 当前候选版固定存档格式 18。P22 之前的内部测试档会归档到 `recovery/legacy/` 后重新开始。

## 暂不包含

亡旗战场、沉金港、无光矿脉、第二主角职业、永久死亡、第三远征队、音频、手柄、Steam、联网与玩家交易属于后续版本范围。

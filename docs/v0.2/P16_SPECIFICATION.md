# P16 怪物、等级、仓库与过滤器规格

> 状态：已确认并实现
> 更新日期：2026-08-28
> 所属版本：v0.2

## 1. 阶段目标

P16 建立剧情至 T20 的正式怪物等级、敌人家族、稀有怪和难度基础，同时完成文档版本化、装备批量处理、仓库排序和掉落过滤器交互收敛。P16 不制作 48 种怪物的最终逐帧美术；正式怪物主体、动作和技能特效仍由 P21 统一制作。

## 4. 装备批量处理与排序

“装备与仓库”工具栏提供：

- 最高稀有度：基础、魔法、稀有、传奇、神话，按“所选稀有度及以下”处理，默认魔法；只有显式选择“神话及以下”才允许处理神话装备。
- 范围：整理背包、仓库、两者；选择物品时默认跟随其所在容器。
- 批量出售、批量分解。
- 按连接数整理、按稀有度整理。

批量操作始终排除已装备、锁定和任务/关键装备；神话装备默认保护，只有显式选择“神话及以下”才会进入目标，并在确认框显示不可恢复警告。制作底材默认排除，但玩家可显式勾选“包含制作底材”并在二次确认后处理。出售结果进入 20 格回购列表，确认窗口提前显示将被挤出的数量；分解不可恢复。

确认窗口必须按稀有度列出处理数量、预计金币或铁屑、受保护数量和传奇警告。

排序固定为降序：

```text
连接数排序：连接数 → 稀有度 → 物品等级 → 名称
稀有度排序：稀有度 → 连接数 → 物品等级 → 名称
```

## 5. 掉落过滤器

过滤器页面只保留一个【新增规则】按钮。点击规则正文使用同一弹窗编辑；规则行保留启用、上移、下移、删除和拖曳排序，删除克隆、测试、单独新增五连规则和单独新增方案缺口规则。

规则从上到下首次匹配，未匹配时默认保留。一条规则内部的 Match 条件全部采用 AND；需要 OR 时建立多条规则。

P16 编辑器支持：

- 稀有度等于、至少、至多、区间
- 装备类别、装备槽位、指定底材
- 最低/最高物品等级
- 最低/最高连接数
- 指定词缀族及最低数值
- 是否满足当前技能方案连接缺口
- 处理方式：保留、出售、分解

锁定、任务/关键、首次获得、五连和六连属于系统保护，只在页面顶部显示摘要，不进入普通规则列表。v0.1 的五连/六连规则迁移为系统保护，其余规则保留并使用新编辑器显示。

## 6. 怪物体系

P16 提供 6 个家族、每族 8 种、共 48 种非 Boss 怪物：

- 烬骸军团：第一章基础敌人，覆盖近战、冲锋、远程、施法和战旗支援。
- 霜原猎群：第二章敌人，强调快速接敌、冰缓区域和召唤兽群。
- 沉墓亡者：第三章敌人，强调尸体爆发、远程骨矢和墓潮支援。
- 血炉造物：第四章敌人，强调高护甲、重击、地面熔炉和机械支援。
- 虚空教团：第五章敌人，强调混合远近程、地面危险和召唤。
- 裂界异兽：70 级异界开始进入混合怪物池。

每个怪物记录家族、战斗职责、主动技能、攻击距离、移动速度、攻击速度、命中、防御和威胁点。战斗职责包括近战、远程、施法、冲锋、召唤和支援。

## 7. 魔法、稀有与怪物词缀

怪物稀有度为普通、魔法、稀有、Boss：

- 魔法怪成组出现，拥有 1～2 个词缀。
- 稀有怪作为首领并携带护卫，拥有 3～4 个词缀。
- 同节点全部怪物同时登场，不生成后续隐藏波次。
- 怪物数量提高时，单怪伤害不再按总人数线性摊薄；高密度节点真实提高总威胁。

18 个词缀为：巨硕、迅捷、铁皮、撕裂、尸爆、秘法护体、吸血、抗性、精准、狂怒、压制、再生、迅捷光环、坚固光环、烈焰附体、冰霜附体、风暴附体、虚空附体。元素附体、两种光环和重复速度类型存在互斥组，生成器不得创建矛盾组合。

## 8. 难度与战斗规则

怪物生命、伤害和防御按 1～120 怪物等级缩放；60 级后增加终局二次曲线。魔法、稀有、Boss分别应用额外生命与伤害倍率，地图词缀和裂渊倍率在此基础上继续相乘。

怪物职责决定实际站位、攻击范围和移动策略。重击、冲锋、齐射、秘法投射、持续地面、尸体爆发、召唤和战斗光环进入攻击细节与伤害倍率；战斗报告可通过怪物 ID、稀有度、技能名和词缀追踪威胁来源。

第一章普通节点不强制生成稀有首领，保证基础构筑能够完成最初节点；从剧情精英节点开始正式执行构筑检查。初始角色不再保证无操作挂机通关五章，失败后停在当前节点等待玩家换装、加点或调整技能。

## 9. 存档、验证与验收

- 存档格式升级到 16，仅承诺正式 v0.1 Demo 存档迁移。
- 自动测试覆盖等级表、旧 `AreaLevel` JSON、48 怪物/六家族、18 词缀、怪群稀有度、排序、批量保护和过滤器组合条件。
- Debug/Release 编译、全部 `dotnet test`、Godot 无界面导入与启动检查必须通过。
- UI 验收需要确认弹窗未超出标准窗口、过滤规则可以新增/编辑/移动/删除、批量处理不会越过安全保护。

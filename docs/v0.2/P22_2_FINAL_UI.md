# P22.2 v0.2 最终界面收口

P22.2 是 v0.2 的最后一次功能更新，不增加玩法内容，集中修正终局引导与三类天赋画布的界面层级。

## 统一信息入口

- 自绘标题栏右上角增加常驻 `?` 按钮。
- 信息页集中提供快速流程、完整旅程状态、系统操作说明和词缀库。
- 原角色页中的词缀图鉴迁入信息页，词缀展示继续与装备生成共用同一目录。
- T16 后的旅程指引明确要求继续刷图达到 100 级，再从“远征 → 异界与突破”挑战门扉；升华页本身不增加来源清单。

## 三类天赋画布

- 主天赋、升华和异界天赋统一使用全页面底层画布。
- 背景、连接和节点共享平移与缩放，取消固定尺寸嵌入画布及外层滚动容器。
- 搜索、方案、点数、节点操作和终局入口作为固定半透明 HUD 绘制在画布上层。
- HUD 接收自身输入，空白画布继续支持拖曳与以鼠标位置为中心的缩放。
- 主天赋小地图上移，避免被底部操作 HUD 遮挡。

## 验收

- Windows PowerShell 5.1 下 Debug/Release 门禁通过。
- 三类画布在 Godot 导入和启动检查中不得产生错误。
- 稳定性测试模式使用按进程隔离的临时存档，测量结果不受玩家现有存档规模影响，也不会改写正式存档。
- T16、100 级门扉、T17～T20与灰烬天垒的既有玩法及奖励规则保持不变。

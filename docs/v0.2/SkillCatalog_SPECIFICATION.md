# SkillCatalog 技能石底层与内容规格

状态：已定稿并实施

依赖：Skills 装备孔组、Inventory 怪物/等级/过滤器

范围：技能底层、30 主动、48 辅助、五类伤害、实战报告，以及三项战斗/过滤器修正

## 1. 已确认规则

- 游戏第五类伤害统一称为“虚空伤害”，对应“虚空抗性”；“混沌”只保留在既有货币名称中。
- 技能兼容由展示标签、执行能力、辅助条件三层判断。辅助必须满足全部/任一能力，不能命中排除能力，同一孔组还要通过互斥规则。
- 转化顺序固定为：物理 → 闪电 → 冰霜 → 火焰 → 虚空。辅助不会反向改变前序，也不会用一颗辅助临时生成的能力去解锁另一颗辅助。
- 血爆处决允许清除目标当前流血，并把剩余流血伤害的一部分引爆。
- 创伤积压允许对角色造成自伤，以换取可累积的近战物理收益。
- 钢铁护卫与复仇反震强制要求装备盾牌。
- 铁誓战旗与裂阵战旗允许同时启用；保留资源分别结算。
- 技能默认接受逐技能优先级、目标、生命/法力、怪群数量、距离、危险度和 Boss 条件的自动战斗规则。

| 铁誓战旗 | 保留光环 | 保留 15% 法力，提高物理伤害与护甲 |

## 3. 辅助技能（48）

| 类别 | 技能 |
|---|---|
| 基础与资源（10） | 扩大范围、攻击速度、流血、生命消耗、追加连锁、残暴、多重投射、极速投射、急促战吼、血之汲取 |
| 命中与施法（8） | 处决、法术回响、元素集中、附加火焰、附加寒霜、附加闪电、精准暴击、集中效应 |
| 猛击与近战（9） | 重势、三叠重击、震域、余波、贴身搏杀、裂甲、透甲、镇压、震荡蔓延 |
| 流血与防御（9） | 深创、疾血、血痕播散、残酷、嗜血、创伤积压、坚阵、复仇增幅、格挡触发 |
| 战吼/光环/投射（7） | 号令增幅、回声战吼、誓旗增幅、贯穿、裂射、归返、疾咏 |
| 转化与触发（5） | 雷铸转化、霜流转化、焰化转化、虚蚀转化、受创触发 |

关键互斥：残暴与任何非物理附加/转化互斥；嗜血与提供流血能力的辅助互斥；触发辅助不能支持保留或战吼。贯穿、裂射、归返只支持投射物；战吼、战旗、反击和盾牌技能分别检查对应执行能力。

## 4. 战斗与报告

- 物理、火焰、冰霜、闪电、虚空分别进入护甲/对应抗性结算；怪物词缀可提供对应抗性。
- 通用执行器处理单体、锥形、圆形、投射、连锁、位移圆形和地面范围；技能不再依赖逐颗硬编码才能进入自动战斗。
- 异常事件至少记录流血、点燃、冰缓/冻结、感电、麻痹、侵蚀/凋零、眩晕和破甲。
- 战斗报告按技能统计伤害与次数，并从事件中解析实际辅助位掩码、伤害分型与异常来源。
- 正式战斗不再有默认限时；显式测试/诊断上限仍允许返回 Timeout，以防错误配置导致无界测试。

## 5. 同批修正

- 过滤器“新增规则”弹窗改为非独占、可缩放、可滚动内容，保存/取消按钮保持可操作。
- 地图/远征失败时，根据所有尝试中已击败怪物占实际生成怪物的比例，结算角色经验和装备；不发放完成奖励、地图、货币、Boss 被动点或进度。
- 主线和主线重放失败时，按已击败怪物结算角色经验、技能经验与物品；固定剧情奖励仍只在胜利时发放。

## 6. 验收

1. 目录严格为 30 主动、48 辅助，稳定 ID 唯一。
2. 合法辅助可装入，能力不满足或互斥组合必须拒绝并给出原因。
3. 五类伤害、固定转化顺序、护甲/抗性可由确定性测试复现。
4. 新主动技能可被 AI 选择并在战斗报告中出现；盾牌技能无盾不可用。
5. 默认战斗没有限时；角色死亡仍结束战斗。
6. 失败结算只包含已击杀收益，不包含通关收益。
7. 过滤器新增、编辑、保存和取消均可用。

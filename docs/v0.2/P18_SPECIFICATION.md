# P18 铁誓者三升华与资源循环规格

> 状态：已定稿并实现
> 所属版本：v0.2
> 前置：P17 技能标签、伤害类型、异常与战斗报告

## 1. 阶段目标

P18 将铁誓者原有的线性突破天赋替换为三套互斥升华：血征者、壁垒使、破阵者。每套升华包含六个方向，每个方向固定为“强化节点→核心节点”，共 12 点。中心徽记免费，不算节点；单个角色最多获得 8 点，所以最多完成四个方向。

升华点来源固定为：第三幕完成 2 点、第五幕完成 2 点、100 级最终突破 2 点、灰烬天垒首次击杀 2 点。升华点总上限 8。首次选定一套升华后不能跨树分配；节点右键退还，强化节点花费 2,000 金币，核心节点花费 10,000 金币；整树重置 50,000 金币，更换升华 100,000 金币。

角色与物品→天赋页增加“主天赋 / 升华”子页。升华树使用六辐放射图，支持悬浮说明、左键分配、右键退还、拖曳和平滑缩放。旧异界页不再显示升华按钮。

## 2. 血征者

| 方向 | 强化节点 | 核心节点 |
|---|---|---|
| 生命代价 | 血肉薪火：最大生命提高5%，技能生命消耗降低10% | 血铸契约：非法术攻击改用生命，消耗至少为最大生命2%；支付生命的攻击命中和流血造成50%更多伤害 |
| 双流血 | 深红刀口：流血概率提高25%，流血伤害提高15% | 双痕法则：最强两条流血同时生效，每条按80%结算 |
| 裂创 | 急血奔流：流血伤害速度提高15%，持续时间缩短10% | 裂创连击：命中流血敌人获得裂创，最多3层，每层再提高15%流血伤害速度 |
| 血怒 | 沸血战意：最近3秒支付生命后攻击速度提高8% | 血怒不息：支付生命、施加流血、击杀流血目标获得血怒；20层时为40%更多物理/流血伤害和10%攻击速度 |
| 低生命 | 濒战本能：低生命时偷取、生命药剂恢复和攻击速度提高 | 死战不退：生命不高于50%时物理命中和流血60%更多，受到击中伤害降低25%，免疫眩晕 |
| 赤潮恢复 | 饮血收割：物理攻击伤害1%生命偷取 | 赤潮归身：流血击杀传播120%剩余流血并回复4%最大生命；对稀有/Boss持续伤害时每秒回复4%，恢复触发后2秒受到击中伤害降低20% |

生命消耗不设置 AI 安全线。唯一硬规则是本次支付不能直接把角色杀死，因此 AI 可以把生命消耗到接近 1 点。

## 3. 壁垒使

| 方向 | 强化节点 | 核心节点 |
|---|---|---|
| 护甲 | 层叠甲幕：护甲提高25%，最大生命提高5% | 百炼甲幕：30%护甲参与元素击中减伤，元素击中伤害再降低20% |
| 攻击格挡 | 盾列操练：持盾攻击格挡+8%，盾牌护甲提高25% | 绝对盾面：攻击格挡+12%，上限80%；未格挡攻击击中伤害降低20% |
| 反击 | 回震刃缘：反击伤害、冷却恢复和范围提高 | 复仇壁垒：格挡获得复仇，满3层的反击180%更多并回复6%最大生命 |
| 壁垒层 | 受击成垒：未格挡攻击后短时间提高护甲 | 不破阵地：每次受到未格挡攻击后获得1层，最多5层；每层击中减伤5%、反击10%更多，3层起回复2%/秒，5层回复4%/秒；成功格挡攻击时反击使用旧层数后清空。法术格挡不获得也不清空层数，节点结束时清空 |
| 护卫 | 守护轮转：护卫冷却恢复和持续时间提高 | 守誓疆域：最大生命提高20%，战旗保留降低50%、效果提高30%；护卫期间额外25%击中减伤并回复5%最大生命 |
| 法术格挡 | 咒击偏转：持盾法术格挡+8% | 镜铁守誓：获得攻击格挡率60%的额外法术格挡；成功法术格挡后该次法术伤害降低70%，未格挡法术击中伤害降低25% |

## 4. 破阵者

| 方向 | 强化节点 | 核心节点 |
|---|---|---|
| 双手武器 | 巨兵驾驭：双手伤害提高15%，攻击速度提高8% | 重兵裁决：双手攻击击中60%更多，攻击速度降低10% |
| 余震 | 震域扩张：猛击范围提高20%，伤害提高15% | 震岳余势：猛击命中0.5秒后，对同一目标造成等于原始实际击中100%的余震 |
| 行军 | 踏阵而行：移动技能冷却恢复提高25%，移动和猛击范围提高15% | 裂阵行军：累计实际移动6米获得永久保留的行军势；下一次猛击消耗它，范围提高50%、伤害60%更多；击杀最多每2秒重置一次移动技能冷却。自然接敌移动和移动技能计入，敌人强制位移不计入 |
| 眩晕 | 撼魂重势：眩晕积累提高40%，持续时间提高25% | 山崩之王：稀有/Boss可完整眩晕；眩晕期间承受100%更多伤害，触发时产生150%击中震波，Boss解除后5秒免疫再次眩晕 |
| 破甲 | 碎甲专断：物理攻击每次使用有25%概率额外施加1层破甲 | 碎城铁律：破甲上限8层，每层降低12%护甲；满层额外承受50%更多物理伤害 |
| 战吼 | 号令回响：战吼冷却恢复提高30%，持续时间提高25% | 号令无尽：战吼瞬发且不占攻击动作；接下来4次近战攻击50%更多，多个战吼只取最高效果 |

## 5. P18 同批资源调整

- 新角色除初始生命药剂外，在药剂栏2获得一瓶法力药剂。
- 生命与法力药剂均由击杀充能并自动使用。普通、魔法、稀有和Boss分别提供1、2、4、6点充能；生命药剂沿用 AI 生命阈值，法力低于35%时自动恢复30%最大法力。
- 所有“攻击且非法术”技能的基础法力消耗降低20%，至少仍消耗1点；法术不受影响。
- 角色默认每秒法力恢复从最大法力5%提高到6%，再乘已有法力恢复提高词缀。

## 6. 数据、报告和基准构筑

节点使用稳定 ID 和数据目录，存档只保存升华类型、已分配节点及四类点数来源标志。旧测试期线性铁誓突破节点不迁移为新节点，但已获得升华点保留。

战斗报告记录升华余震、格挡种类、异常、药剂使用和击杀充能。维护六套固定基准构筑：每套升华各一套开荒装备和一套终局装备，均恰好使用8点；后续平衡阶段用它们覆盖剧情、T1、T10、T16、T20和灰烬天垒。

## 7. 验收条件

1. 三套升华各有6个方向、12个节点，连接关系和8点上限受自动测试约束。
2. 三套升华不能混点；四种点数来源只发放一次；存档往返保持选择与分配。
3. 核心输出节点具备40%～60%更多伤害量级，强条件节点可到100%以上；防御核心提供20%以上的单次击中防线及持续恢复。
4. 六套基准构筑完整存在，节点均合法且各用8点。
5. 初始蓝药、击杀充能、自动喝药、攻击耗蓝和默认回蓝均有自动测试。
6. Release 编译、全部 `dotnet test`、Godot 导入与无窗口启动检查通过。

# EquipmentArt 平衡、装备表现与 v0.3 封版规格

> 状态：已实施
> 产品版本：`v0.3.0`
> 存档格式：20
> 前置阶段：Characters / Characters.1 / Archetypes

## 1. 交付范围

EquipmentArt 作为 v0.3 的单一封版阶段，不再拆分新的 P 编号。本阶段完成六职业起点花园、天赋拓扑与画面一致性、Archetypes 装备图标、装备合法性、全底材固有词缀、统一物品详情、打造强化、传奇完整化、36 套升华基准构筑和 v19 存档迁移。

亡旗战阵仍延期到 v0.4；沉金港、无光矿脉以及新的大型玩法循环延期到 v0.5。

## 2. 六职业起点花园

- 每个职业起点拥有三个装备主题小簇，每簇由四个小点、一个显著点和一条主干连接组成。
- 斗士：双手重兵、单手锤盾、双持战法。
- 侠客：弓与箭袋、匕首双持、投射陷阱。
- 灵能使：召唤媒介、咒术法杖、光环祝福。
- 秘术师：法杖秘术、焦点护盾、元素虚界。
- 僧侣：徒手缠带、灵兽护符、幻身步法。
- 隐士：符刃交错、构装偶像、魔铠一体。
- 纯属性职业在起点两步内获得三个非主属性 `+30` 显著点；混合职业获得两个缺失属性 `+30` 和一个双主属性 `+15/+15` 显著点。
- 主环集群由每簇十个小点压缩为八个；起点花园新增 144 个节点后总数仍固定为 1,200。
- 保留起点到原两条主干的连接，确保 v19 路径迁移和旧引导不形成死路。

## 3. 天赋画面契约

- 旧 `art-passive-backdrop.png` 不再承担节点和连线拓扑。
- 背景环、方向线、全部未分配连线、已分配连线、节点、点击判定和小地图统一读取 `PassiveTree` 的坐标与邻接数据。
- 画布继续支持拖曳和缩放；边界限制使用同一 `LayoutExtent`，不会拖出天赋视窗。
- 搜索高亮、路径规划、珠宝半径和双击加/洗点规则保持不变。

## 4. 装备与美术

- 130 个底材统一使用显式的一底材一图标映射，不再按类别哈希、复用同一轮廓或依赖目录排序碰运气。
- 武器以“单手/双手”表示装备方式，以剑、斧、锤、匕首、弓、法杖和符刃表示真实武器子类型；图标、天赋标签和详情类型读取同一子类型。
- Archetypes 的 50 个新底材沿用 Art 的粗轮廓、深色描边、钢铁/皮革/黄铜像素语言；同类各阶拥有不同造型，高阶通过材质、宝石、符文与角标显示价值提升，而不是只换颜色。
- 十类轮廓固定为：弓、匕首、法杖、箭袋、施法焦点、召唤媒介、徒手缠带、灵兽护符、符刃、构装偶像。
- 25 件传奇按稳定 ID 显式映射到其实际底材轮廓；例如鸦群答卷固定为头盔、灰烬之心固定为胸甲，不再使用循环类别生成图标。
- Archetypes 的 50 枚主动石和 40 枚辅助石使用专用 90 格图集，一石一格稳定映射；禁止稳定 ID 哈希随机选图或重复占位。
- 箭袋仅能在主手为弓时装备；换成任何非弓武器会自动卸下箭袋。
- 单手武器允许合法双持，但副手单手武器要求主手也是单手武器。

## 5. 物品详情与底材固有词缀

- 130 个装备底材全部拥有可重掷、有明确数值区间的固有词缀；旧档中固有值为 0 的物品按该底材最低值兼容。
- 导入底材不再显示“远古胸甲·8”“远古单手武器·5”一类占位名；名称改为雅致环甲、破血钉锤、虚界巨斧等与造型、武器子类和固有属性一致的正式名称。
- 详情统一按以下顺序显示：稀有度与名称/品质、底材、物品等级与类别、需求、基础战斗数值、连接孔、基底词缀、附魔、传奇效果、全部前缀、全部后缀、状态、出售价格。
- 显式词缀始终先前缀后后缀，并显示 T 级、数值区间和来源。
- 80 个历史底材与 50 个 Archetypes 底材统一使用 `equipmentArt-equipment-atlas.png`；每个稳定 ID 独占一格，不再读取 Art 的旧装备图集。
- 武器、护甲、盾牌、手套、鞋、腰带、护符、戒指、药剂及十类 Archetypes 专属装备分别使用类别母版；裁切按类别固定视觉占位与底部锚点，确保完整轮廓和一致可读尺寸。
- 25 件传奇使用 `equipmentArt-legendary-atlas.png`，图标严格继承实际底材类别；旧存档物品在恢复时按稳定 ID 重绑定当前底材名称、标签、固有词缀和美术映射。

## 6. 传奇与打造

- 25 件传奇全部使用明确数值规则文本，并拥有 4～6 条满值显式词缀、满值固有词缀、至少 `+10` 品质；神话装备为 `+20` 品质。
- 所有传奇稳定 ID 均进入统一确定性效果表，覆盖伤害、承伤、移动、护盾/法力恢复、药剂、旗帜、命能、投射物、触发与重燃。
- 页面名称由“金属”改为“打造”。材料、附魔和炼金配方悬浮均显示完整效果、条件、消耗与产出。
- 基础加工增强为：武器物理伤害提高 35%、基础防御提高 30%、最大生命 `+40`。
- 八种工坊附魔整体提高，最高阶断界王印提供 120% 物理伤害，不灭王印提供 `+160` 最大生命。

## 7. 天赋、升华与基准构筑审计

- 普通天赋的单手、剑、斧、锤、匕首、弓、法杖、徒手、盾击和双持增伤根据当前实际配装结算，不再只进入未读取的专精字典。
- Characters.1 已确认的多重投射、军团、光环保留、光环效果、祝福、元素转化、最大护盾、护盾充能和炮台规则保持数值不变。
- 传奇效果使用统一运行时解析入口；目录测试要求每件传奇都有具体规则、显式词缀与执行处理。
- 18 个升华各维护一套开荒与一套终局基准构筑，总计 36 套，每套固定 8 个升华节点。

## 8. 存档迁移与验收

- 存档格式从 19 升级到 20。
- v19 迁移保留基础职业、装备、技能石、剧情、升华、已获得点数、记忆灰烬和其他进度；清空旧主天赋分配、专精选项和已插珠宝，让玩家免费重新规划 V3.1 天赋树。
- v18 迁移规则继续保留。
- 自动门禁覆盖：1,200 节点和唯一坐标、六个起点花园、全底材固有词缀、箭袋/双持合法性、显式美术索引、25 件传奇效果、36 套基准构筑和 v19→v20 迁移。

# v0.3 六职业、十八升华与主天赋树 V3 总规格

> 状态：P23 与 P23.1 已实施，下一阶段 P24
> 更新日期：2026-08-30
> 产品版本：`v0.3`
> 实施阶段：P23～P25

## 1. 版本定位

v0.3 是职业与构筑体系扩展版本。版本目标是在不增加大型异界玩法循环的前提下，将当前仅完整支持斗士的内容扩展为六个基础职业、十八个互斥升华，并重构主天赋树的主题与专精，使不同武器、资源、防御和技能机制拥有真正不同的成长路线。

亡旗战场、沉金港和无光矿脉整体延期到 v0.4。v0.3 不开发永久死亡挑战、第三远征队、Steam、联网或玩家交易，也不以扩大现有地图玩法数量作为验收目标。

## 2. 已确认的产品范围

- 完整开放 6 个基础职业和 18 个升华。
- 基础职业决定初始属性、主天赋树起点、初始装备与技能、自动战斗倾向及可选择的三个升华。
- 基础职业不提供隐藏的专属伤害倍率；技能石原则上不做职业绑定，跨职业构筑仍由属性、装备、天赋和机会成本约束。
- 基础职业创建后不能更换；玩家通过其他存档槽体验不同基础职业。
- 同一基础职业的三个升华之间允许付费更换，不允许跨基础职业转职。
- 十八个升华统一沿用六方向结构：每个方向为“强化节点 → 核心节点”，每个升华 12 个可分配节点，角色最多获得并使用 8 个升华点。
- 升华点继续来自第三幕、第五幕、100 级门扉突破和灰烬天垒首次击杀，各 2 点。
- 不恢复独立的 105～120 级突破树；101～120 级的成长继续由普通天赋点、装备、技能和高阶内容承载。
- 主天赋树维持约 1,200 节点的规模，但升级为 V3 内容结构；目标是降低同质化，而不是继续增加节点总数。
- v0.3 仅分为 P23、P24、P25 三个正式阶段。职业可以在阶段内部按可验证切片提交，不再为每个职业建立独立 P 阶段。

## 3. 六个基础职业

| 基础职业 | 属性倾向 | 核心领域 | 三个升华 |
|---|---|---|---|
| 斗士 | 体魄 | 重型近战、流血、护甲、盾牌 | 血战士、铁壁卫、破军者 |
| 侠客 | 灵巧 | 弓、匕首、暴击、毒素、陷阱 | 神射手、影刃客、毒术师 |
| 灵能使 | 精神 | 召唤、光环、祝福、诅咒 | 牧魂师、颂灵师、咒契师 |
| 秘术师 | 能量 | 元素法术、虚空伤害、能量护盾 | 元素使、虚空学者、秘盾师 |
| 僧侣 | 灵巧＋精神 | 徒手连击、灵兽、幻身 | 行武僧、灵兽使、幻身宗师 |
| 隐士 | 体魄＋能量 | 魔法近战、魔铠、构装体 | 刻印师、魔铠师、铸像师 |

前四个纯属性职业使用四个主要起点。僧侣位于灵巧与精神之间，隐士位于体魄与能量之间；六个正式名称、起点、初始属性和初始技能已在 P23 定稿。

## 4. 十八个升华的玩法边界

### 4.1 已实现的斗士升华

- 血战士：生命消耗、流血、血怒、低生命与击杀回复。
- 铁壁卫：护甲、攻击/法术格挡、反击、护卫与受击成垒。
- 破军者：双手重击、余震、眩晕、破甲、战吼与行军蓄势。

这三套升华保留现有节点结构和核心规则，只在全职业平衡阶段进行必要调整。

### 4.2 新增十五个升华

| 升华 | 主要玩法边界 |
|---|---|
| 神射手 | 远距收益、移动射击、额外投射、穿透、连锁、疾风层数 |
| 影刃客 | 暴击、标记、背袭、闪避反击、隐匿、处决 |
| 毒术师 | 中毒层数、毒素扩散、陷阱、药剂、腐蚀与毒爆 |
| 牧魂师 | 召唤军团、尸体利用、属性继承、主动指令与复生 |
| 颂灵师 | 光环容量、祝福、战歌、佣兵强化与队伍保护 |
| 咒契师 | 多重诅咒、法力牺牲、弱化扩散、灵魂契约与咒印处决 |
| 元素使 | 元素转化、火焰、冰霜、闪电、元素异常与三元素共鸣 |
| 虚空学者 | 虚空持续伤害、侵蚀、凋零、禁术代价、献祭与虚空爆发 |
| 秘盾师 | 最大护盾、护盾充能、护盾施法、吸收、法术反击与破盾收益 |
| 行武僧 | 徒手、连击、攻防姿态、位移攻击、反击与终结技 |
| 灵兽使 | 单只核心灵兽、形态切换、协同攻击、伤害分担与濒死救援 |
| 幻身宗师 | 幻身生成、技能复制、位置交换、残影攻击与合击 |
| 刻印师 | 武器灌注、攻击与法术触发、元素转化、刻印爆发 |
| 魔铠师 | 护甲与护盾混合、受击蓄能、吸收、过载与破盾反击 |
| 铸像师 | 构装体、炮台、符文阵、主动指令、自毁与重铸 |

升华之间必须保持明确边界：牧魂师负责召唤军团，灵兽使负责单只核心伙伴，铸像师负责机械构装与阵地装置；影刃客负责匕首暴击处决，行武僧负责徒手连击，刻印师负责武器与法术联动；铁壁卫负责盾牌格挡，魔铠师负责护甲与能量护盾混合。

所有核心节点应改变技能、资源、AI 或防御规则，不能只提供可替代的通用增伤。十五套新增升华的 180 个节点及数值已在 P23.1 一次完成。

## 5. 主天赋树 V3

### 5.1 重构目标

当前 V2 天赋树虽然拥有约 1,200 个节点，但大量集群由相似模板生成，实际选择集中在伤害、速度与防御的重复组合。V3 保留共享大树、拖曳缩放、最短路径、断路保护、专精唯一性、规则天赋和记忆珠宝，同时重新组织主题、显著、专精、基石与职业起点。

### 5.2 必须覆盖的专精领域

- 武器：单手、双手、剑、斧、锤、匕首、弓、法杖、徒手、盾牌、双持、攻击触发法术。
- 恢复与资源：生命偷取、法力偷取、护盾吸收、击中回复、击杀回复、持续恢复、药剂恢复、低生命恢复、过量偷取保留，以及生命/法力/护盾消耗转换。
- 技能机制：投射物、范围、持续伤害、异常、暴击、召唤军团、单体灵兽、光环、祝福、诅咒、陷阱、构装体、战吼、反击、位移、触发与保留。
- 防御：护甲、闪避、能量护盾、混合防御、攻击格挡、法术格挡、法术压制、元素抗性、虚空抗性、异常防护、受击恢复、护卫与屏障。

上述清单规定 V3 的覆盖范围，不代表最终每一项都必须拥有相同数量的集群。详细主题数量、分布、专精六选一效果、显著和基石规则在 P23 开发前分批确认。

### 5.3 结构原则

- 六个职业拥有六个不同起点；混合职业起点不能简单复用纯属性职业起点。
- 各武器路线必须具有不同机制，不得只替换名称和伤害类型。
- 每个集群拥有可辨认的单一主题，普通节点用于建立该主题，显著节点形成局部机制，专精提供同主题下的规则选择。
- 基石必须同时包含显著收益和可理解的代价，并能够改变构筑决策。
- 最高仍只能投入 120 个普通天赋点；节点总数保持约 1,200，不把规模扩大视为质量提升。
- 洗点后所有已分配节点必须仍连接到当前职业起点。
- V3 存档迁移保留已获得普通天赋点、记忆灰烬和记忆珠宝，但清空 V2 分配并让玩家重新加点，避免旧节点 ID、职业起点和路径失效。

## 6. 新职业所需的通用战斗能力

v0.3 必须补齐新职业正常运作所需的执行能力，但不借此扩展新的独立玩法循环：

- 弓、匕首、法杖、徒手、双持和施法副手的装备及攻击规则。
- 远程角色的保持距离、移动施法、目标优先级和危险区域规避。
- 陷阱的布置、数量上限、触发、继承和结算；地雷与图腾不进入 v0.3。
- 召唤军团、单只灵兽和构装体分别使用独立的数量、继承、AI、死亡与复生规则。
- 光环、祝福、战歌和诅咒只作用于实际参战单位，不产生额外全局后台收益。
- 能量护盾充能、受击中断、护盾施法、吸收屏障与破盾事件。
- 标记、背袭、毒素、连击、姿态、触发、暴击与处决等通用战斗事件。
- 战斗报告分别统计主角、召唤物、灵兽、构装体、陷阱、持续伤害和升华来源。

P23 已固定召唤物上限 6、核心伙伴上限 1、构装体上限 3、陷阱上限 3，并建立能量护盾受击中断和充能状态。继承比例、远程安全距离及各职业的具体 AI 行为在后续内容实现时继续定稿。

## 7. 内容规模目标

以下数字作为容量和验收预算，允许在 P24 详细设计时小幅调整，但不得让任一职业缺少完整构筑链：

- 主动技能累计约 80 个，即在现有 30 个基础上新增约 50 个。
- 辅助技能累计约 88 个，即在现有 48 个基础上新增约 40 个。
- 新增约 50 个装备底材和约 45 个词缀族，覆盖新武器、施法副手、箭袋、召唤媒介与混合防御装备。
- 十八个升华各维护开荒与终局两套固定基准构筑，共 36 套；现有六套斗士构筑计入总数。
- 五个新增主角拥有四方向正式动作和主要技能表现。
- 十五套新增升华拥有独立徽记、背景和可辨认的节点主题。

## 8. 三个实施阶段

### P23：六职业底层与主天赋树 V3

- 建立稳定的基础职业、属性倾向、六起点和升华归属数据模型。
- 重构角色创建、职业显示、初始装备技能、AI 倾向和旧存档迁移。
- 定稿并实现主天赋树 V3 的主题分类、拓扑、专精、显著、基石和珠宝兼容。
- 建立新职业共用的战斗实体与事件底层，包括召唤/伙伴/构装、陷阱、护盾、触发、连击和远程 AI；P23 只要求可验证的通用能力，不要求完成十五套升华内容。

P23 已完成。实施明细见 [`P23_SPECIFICATION.md`](P23_SPECIFICATION.md)。

### P23.1：十八升华完整实现

- 保留并复核斗士三套既有升华，完整实现其余十五套升华的节点、连接、规则、数值、界面说明和自动测试。
- 每个升华仍为六方向、每方向“强化节点 → 核心节点”，共 12 个节点；必须至少形成两条可验证的机制构筑路线。
- P23.1 是 P23 的内容子阶段，不增加新的正式 P 编号。

P23.1 已完成。实施明细见 [`P23_1_SPECIFICATION.md`](P23_1_SPECIFICATION.md)。

### P24：五职业配套构筑内容

- 一次阶段内完成侠客、灵能使、秘术师、僧侣和隐士的技能、辅助、装备、词缀、AI 与正式表现。
- 每个职业按“数据与规则 → 技能装备 → 三升华 → 界面表现 → 自动测试”的完整切片提交，避免只完成目录或占位入口。
- 补齐五个主角的四方向动画、主要技能特效、十五套升华背景和信息页指引。

### P25：平衡、迁移与 v0.3 封版

- 维护并审计 36 套固定基准构筑。
- 覆盖剧情、T1、T10、T16、T20、门扉突破和灰烬天垒的清图、攻坚、生存、资源与收益验证。
- 完成旧档迁移、过滤器与仓库适配、职业/升华引导、性能、长稳、Windows 分发和 v0.3 发布门禁。

## 9. 延期到 v0.4

- 亡旗战场。
- 沉金港。
- 无光矿脉。
- 与上述玩法配套的新异界天赋、专属奖励、失败规则和独立界面。
- 地雷、图腾、永久死亡、第三远征队、Steam、联网与玩家交易。

## 10. 待阶段确认

- 新增约 50 个主动技能、40 个辅助技能、50 个底材和 45 个词缀族的最终清单。
- 召唤物、灵兽、构装体、陷阱、护盾、连击、触发与远程 AI 的职业级精确规则。

这些问题分别在 P23.1 和 P24 开发前确认，不在总规格中提前锁死。

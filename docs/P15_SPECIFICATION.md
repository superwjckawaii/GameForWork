# P15：首个完整可玩 Demo 封版

> 状态：已完成，等待体验验收
> 决策：2026-08-28 全部采用推荐项（A）

## 1. 统一美术

- 采用接近 Taskbar Hero 的低密度精细像素语言：清楚轮廓、有限色板、少量高亮，不追求高分辨率插画质感。
- 统一主角、4 类佣兵、18 种敌人、6 种精英变化、10 个 Boss、12 个地图环境及主要技能/机制表现。
- 角色共享四方向基础动作骨架，但家族轮廓、颜色和关键攻击必须可辨。危险预警同时使用形状、闪烁与描边，不只依赖颜色。

## 2. 教程、旅程与结算

- 教程为非阻塞引导，约 10～15 分钟覆盖战斗、装备、技能石、城镇、地图、机制、制作和离线收益。跳过教程立即开放全部页面；旅程手册可随时重播提示且不重置进度。
- 首次完整流程目标为 8～12 小时等效挂机时间。旅程以击败灰烬天垒为正式完成条件。
- 结算展示构筑、总耗时、死亡次数、地图完成数、城区等级、主要战利品、机制选择和终局成绩；结算后继续游玩，不锁档。
- 离线报告按队伍和地图段落拆分，展示耗时、节点、死亡、掉落、消耗和停止原因，最长结算 48 小时。

## 3. 性能、布局与稳定性

- 标准窗口目标 60 FPS，小窗目标 30 FPS；托盘不渲染。战斗模拟不得造成约 1 秒周期卡顿，悬浮、菜单、按钮和退出响应目标约 100 ms。
- 布局覆盖 1920×1280 大窗、标准窗口和约 384 px 宽小窗；字体支持 80%、90%、100%、110%、120%、130%、140%、150%。
- 自动化覆盖 48 小时离线结算、2 小时可见窗口和 2 小时托盘稳定性；长稳脚本支持在发布门禁中完整运行，日常验证可使用缩短时长。

## 4. 发布物

- 发布 Windows x64 便携 ZIP，自带运行所需文件，不依赖外部数据库或单独安装 Godot。
- 最终门禁包含：干净新号、跳过教程、48 小时离线、突破 Boss、灰烬天垒、损坏存档恢复、Debug/Release 编译、全部测试、Godot 导入与启动、布局和性能检查。
- 不纳入首版：音频、手柄、Steam、联网、第二主角职业和永久死亡。
- 通过门禁后标记 `v0.1.0-demo`；P14/P15 使用内部清晰提交，统一推送并交付玩家验收。

# P8：Demo 主旅程与首次体验

> 状态：已确认并实现  
> Demo 终点：首次击败深渊监守者

## 1. 阶段目标

P8 不新增大型玩法，而是把 P0～P7 已有系统串成陌生玩家无需阅读外部文档也能完成的单线旅程：

`创建角色 → 观察战斗 → 换装/天赋/技能/制作 → 完成五幕 → 派遣两队 → 安全与裂渊地图 → 门票 → 深渊监守者 → Demo 结算`

五幕目标 60～90 分钟，异界至 Boss 目标 30～60 分钟。结算后存档不锁定，玩家可以继续挂机和优化构筑。

## 2. 角色创建与引导

- Demo 只开放已具备真实效果的铁誓者；破阵者从创建界面隐藏。
- 创建角色时可以勾选一次“跳过首次引导”，创建后不能重新开启。
- 未跳过时，每个新目标首次出现均使用独占式像素对话框强制聚焦；确认后自动跳转目标页面。
- 引导与 Demo 主目标合并为一条任务链，不设置独立训练清单。
- 教学不会暂停主线、城镇生产或离线推进。
- 每个旅程目标完成时自动发放固定金币；关键换装、技能目标额外提供一次对应制作金属，且奖励状态随存档持久化，不会重复领取。

## 3. 单线任务

1. 观察一场战斗
2. 完成第一次换装
3. 完成第一幕
4. 分配一个天赋点
5. 查看技能孔组
6. 配置一个攻击技能的目标
7. 完成一次金属制作
8. 完成五幕主线
9. 查看战斗报告
10. 派遣主角
11. 派遣佣兵队
12. 完成安全地图
13. 完成裂渊地图
14. 获得监守者门票
15. 击败深渊监守者

任务使用持久化状态和权威战斗报告判定。在线、离线、存档恢复或旧档迁移造成的进度都能自动补齐。旧存档默认关闭强制引导并补齐不可可靠反推的交互任务，避免集中弹窗。

## 4. 页面解锁

未开放页面完全隐藏：

- 创建后：总览、主线
- 观察战斗后：角色与装备
- 第一幕后：天赋
- 分配天赋后：技能
- 配置技能目标后：旧高级 AI 页面
- 完成制作后：城镇事务
- 完成第五幕后：远征

标准窗口顶部持续显示当前目标和“前往”按钮。迷你窗口只显示一行目标，点击后恢复标准窗口并跳转。旅程手册可重复查看已完成目标和术语，但跳过引导的存档不能重新开启强制教学。

## 5. 停止与失败提示

主线战败、地图耗尽、补给不足、连续失败、仓库空间不足、Boss 门票不足和无主动技能孔组使用常驻警告栏。警告提供原因和“前往处理”按钮，但不会自动修改装备、技能、天赋或远征策略。

失败规则只在玩家第一次真实遇到时呈现，不在创建角色时一次性灌输。

## 6. Demo 结算

首次真实击败深渊监守者时自动显示一次结算页，并持久化“已经展示”。总览保留完成状态与“查看结算”入口，玩家可以反复查看结算并继续游戏。

结算包含现实游玩时间、离线时间、幕数、地图成功/失败、Boss 尝试、等级、主要技能与连接数、最高技能总伤害、装备评分、传奇数量和结算存档哈希。

Boss 练习胜利不完成 Demo。

## 7. 存档与开发能力

- 存档格式升级至 10，P8 旅程、教学选择、已展示步骤、结算状态和时间统计全部持久化。
- “重新开始”先创建手动备份，再把当前数据库移入可恢复的 `trash/`，最后返回角色创建。
- 20 倍速、48 小时测试和性能指标仅在编辑器或调试构建显示。
- 正式构建加载旧档时强制关闭遗留的开发加速状态。

## 8. 角色装备栏修正

项链、左戒指和右戒指统一移动到纸娃娃右下角，与副手处于同一垂直列；物品图标继续在各自装备格中居中。

## 9. 明确排除

P8 不实现城镇建筑升级、佣兵刷新与多人编队、新地图机制、独立异界天赋树、新敌人/Boss/职业/技能、大规模数值调整、新美术或音频。这些内容留给 P9～P11。

## 10. 验收

- 新档的任务顺序、跳过引导、事件任务和时间统计正确。
- 版本 9 存档迁移后不重播强制教学。
- Demo 只由真实深渊监守者胜利完成，结算只自动展示一次。
- Release 编译、全部单元测试、Godot 导入和启动检查通过。

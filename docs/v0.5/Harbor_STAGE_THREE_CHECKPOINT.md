# 沉金港第三阶段：内容与消费者接入

日期：2026-09-09。第三阶段已接入专属港区敌人/精英/首领、第一批底材运行时消费者，并完成普通箱技能石、珠宝、首通保底事务边界。

## 已实现

- 新增 9 个稳定身份的港区普通敌人、3 个港区精英和 3 个港区首领。三个区域分别使用独立普通敌人池、对应精英身份和首领身份，仍复用 `SpatialCombatRunner`、`EnemyRules`、Boss 技能与空间事件消费者。
- 港区首领接入 `Bosses.TryGet`/`CombatProfile`，保留生命阶段、预警、技能和区域规则字段；没有创建第二套战斗系统。
- 第一批底材消费者已接入：断缆手斧低生命更多击中伤害、沉锚重锤近距离更多击中伤害、掠潮长弓移动后投射物更多伤害、潮汐法杖五秒实际耗蓝滚动增伤、返潮重盾格挡后攻法击中增伤、顺流箭袋弓击中后移动速度窗口；回潮/深汐的美德恶德上限继续走正式上限聚合。
- 运行时窗口使用实际 tick、实际支付法力、格挡事件、命中前生命/距离和命中事件，不读取动画或展示文本；新战斗实例清空滚动状态。
- 普通箱冻结完整技能石与珠宝实例；技能石的等级、品质、变异、稳定实例身份在生成时确定，领取不重掷。
- 首通神话在生成时登记防重，并以锁定装备实例进入普通箱；未领取箱内身份参与重复奖励检查，领取失败不消耗箱子。
- 普通箱领取先验证装备/技能石/珠宝全部容器边界，再一次性提交；珠宝仓已满或技能石身份/同名上限冲突时保留原箱。

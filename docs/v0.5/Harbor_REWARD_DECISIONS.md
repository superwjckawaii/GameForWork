# 沉金港与统一宝箱：第一阶段确认记录

日期：2026-09-07。状态：21项规则已确认，第一阶段规格、静态审计及代表场景前测已交付；玩法尚未实现，前测缺陷留待后续修复验收。

开发入口：[v0.5 六阶段开发计划](V0_5_DEVELOPMENT_PLAN.md)。本文取代此前有关宝库数量、风险策略、提前撤离及离线自动选择第一项的讨论草案。

## 港口行动

开始选择难度并支付金币 → 全自动行动与撤离 → 成功获得对应宝箱 → 宝箱累积 → 玩家主动开箱选择一项奖励。

- 难度越高，金币费用越高；途中没有策略或提前撤离选择。
- 行动使用实际移动、战斗和危险判定，重点考验移速与生存。
- 成功撤离才获得港口宝箱；失败损失本次金币且没有港口宝箱，玩家原有角色和装备保留。
- 不再保存供玩家操作的途中待带出装备列表。专属奖励通过成功宝箱发放。
- 未开启宝箱不阻塞连续派遣；派遣次数和金币不足停止等沿用既有交互。

## 两种宝箱语义

| 宝箱 | 来源 | 开启方式 |
| --- | --- | --- |
| 普通战利品箱 | 普通刷图每次结束汇总一箱，包含实际装备、金币、打造材料收益 | 全部领取，支持批量开启；不增加额外选择或改变掉落量 |
| 沉金港宝箱 | 港口每次成功获得一箱，按难度区分 | 逐箱三选一，每项一件装备 |

- 经验直接结算；首通解锁、任务进度直接记录，不因未开箱延迟。
- 地图、门票等继续游玩所必需的续航资源直接到账，不进入宝箱，可按既有派遣规则用于后续自动刷图；装备、金币和打造材料仍开箱领取，金币不因用于入场而例外。
- 普通刷图失败仍保留实际击杀收益，按上述资源分类直接到账或通过普通箱领取；不发完成奖励。
- 在线和离线都只累积宝箱，不自动打开，不默认领取港口第一项。
- 奖励内容与候选顺序在宝箱生成时固定并保存，退出重进不会刷新。
- 普通箱领取后执行正常物品过滤、自动处理和满仓恢复规则；港口手动选中的装备受到保护，不自动卖出或分解。未领取内容不可消费；仓储与恢复区无法接收时保留未领取状态。
- 宝箱独立存放，显示来源、难度、数量及新获得标记。
- “金币进入普通箱”意味着未开箱金币不能用于继续支付港口费用；离线不会为续航自动开箱。

## 实现与验收要求

- 按资源分类分流实际掉落：续航资源直接到账，装备、金币和打造材料封装为普通箱；同一奖励只能走一条路径，防止重复发奖。
- 验证在线、离线及重载恢复下，地图与门票无需开箱即可继续派遣；未领取金币不可支付费用，金币不足正常停止，不后台静默开箱。
- 宝箱生成、选择与领取均需防重；关闭选择页面或恢复存档后仍对应同一宝箱和同一组候选。
- 批量开启普通箱不得绕过过滤与满仓恢复规则，也不得在部分失败后重复领取。
- 已拥有资产不反向装箱；迁移不得重复包装已经结算的收益。
- 显示并分别统计产出、未领取和已领取收益，避免审计把延迟领取误判为掉落损失。
- 港口宝箱选择不阻塞战斗或离线模拟；开箱动画不改变奖励结果。

## 第一阶段统一确认方案

以下 21 项经用户统一同意。初始数值、设计预算和待实测内容保留各自限定，不视为已经完成验证。

| 编号 | 项目 | 已确认方案 |
| --- | --- | --- |
| 1 | 解锁与队伍 | 完成 100 级突破后解锁；主角队伍、佣兵远征队均可参加，沿用活动互斥，不新增队伍。 |
| 2 | 难度与准入 | 三档难度，解锁后均可选择；展示推荐移速、生存及敌人强度，不设属性硬门槛。 |
| 3 | 金币费用 | 每次开始一次性扣费，同档固定价格，不随角色财富上涨；三档初始比例为 1∶3∶8。具体金额依据现有金币产速校准，由第五阶段验证。 |
| 4 | 行动流程 | 进入港区 → 自动推进与开启宝库 → 自动撤离；不选路线、不选策略、不提前撤离，全部完成才成功。途中开启宝库是自动行动，奖励宝箱在成功后生成，两者不是同一次交互。 |
| 5 | 构筑作用 | 实际移速减少危险区暴露和撤离耗时；肉度承受沿途伤害与追击；输出清除阻挡、精英与首领。沿用实际战斗，不用属性评分直接判胜负。 |
| 6 | 危险与时限 | 地面预警、周期危险区和撤离追击；不新增复杂警戒条。设置宽松行动时限防止无限拖延，超时失败，具体时长通过原型确定。 |
| 7 | 内容规模 | 三个港区场景，每次依次经过；三档共享场景，高难增加敌人组合与危险压力。首发预算为 9 种普通敌人、3 种精英、3 个首领，不是每档各做一套。 |
| 8 | 失败与取消 | 团灭、超时无宝箱且不退费，不损失原有装备，不新增救援费用。停止重复派遣完成当前局后停止；立即取消视为放弃本局。默认失败后停止，可设置失败后继续。 |
| 9 | 存档与异常 | 正常退出保存行动，重进继续；离线执行同一规则。扣费、结果与宝箱防重，重载不能更换结果。无法恢复的损坏行动终止，一次性退还本局费用，不发奖励。 |
| 10 | 装备规模与定位 | 首发 18 件特殊巅峰底材、8 件专属传奇/暗金；覆盖武器、防具、饰品及不同构筑。特定用途可明显更强，不无条件淘汰所有现有底材。逐件目录仍需设计。 |
| 11 | 打造兼容 | 底材复用现有打造、品质、词缀等适用规则，传奇沿用现有限制；不新增港口打造币、装备等级或平行强化系统。 |
| 12 | 难度与奖励 | 三档均能获得完整港口装备池；高难提高传奇出现率及高质量底材概率，不抬高巅峰等级上限。港口箱不额外返金币、门票或材料。 |
| 13 | 候选与保底 | 三选一、每项一件；至少一件特殊底材，同箱不重复底材/传奇身份，其余位置按权重抽取。首发不加保底计数、兑换碎片或重选。具体权重通过经济审计校准。 |
| 14 | 专属来源 | 港口专属底材与传奇仅由港口箱产出，不进入普通掉落池。普通箱只包装既有收益，不提高掉落数量或品质。 |
| 15 | 普通箱边界 | 每次刷图成功、失败或取消时汇总已获得的装箱收益；无收益不生成空箱。中途保存累计收益，不提前发箱；完成奖励只在成功时加入。 |
| 16 | Boss 与特殊奖励 | 地图内 Boss 收益并入本次普通箱，独立 Boss 挑战沿用相同资源分类。首通解锁、任务进度、地图和门票直接到账；奖励装备、金币、打造材料装箱。实施前列全资源分类。 |
| 17 | 容量与呈现 | 宝箱不占装备仓库，不设促使玩家频繁清理的容量上限；按来源与难度分组显示数量，内部保留各箱身份及内容。至少验证 48 小时等效离线积累。 |
| 18 | 开箱与过滤 | 普通箱单开或按组批量开，沿用过滤；港口逐箱选择，手选装备保护、不自动卖出或分解。动画可跳过；仓储与恢复区无法接收则保留未领取状态。 |
| 19 | 动画范围与风格 | 全量审核角色、敌人、Boss、主动技能、辅助可见变化、状态与界面动效。保留整体画风，合格效果保留，有问题的修复或重做；纯数值辅助不强加特效。 |
| 20 | 显示优先级 | 危险预警与真实判定一致，任何特效档位均不得隐藏；高密度优先压缩装饰、重复粒子和伤害数字。开箱动画可跳过，不阻塞挂机。 |
| 21 | 验收与性能 | 覆盖小窗、标准窗口、大窗及低中高特效，在固定设备记录前后表现。标准场景以稳定 60 FPS 为目标，压力场景不低于现有基线；具体设备、分辨率和帧耗时阈值由第一阶段实测后写入。 |

# 统一宝箱：资源结算分类表

状态：用户已统一确认资源分类与特殊来源边界；未实现。写入路径的静态处置审计已补齐至[调用点清单](Harbor_SETTLEMENT_CALLSITE_AUDIT.md)，实现后的防重与迁移测试仍须执行，不能将规则确认视为实现或验证完成。

上位规则：[第一阶段确认记录](Harbor_REWARD_DECISIONS.md)。收益数量、掉落条件、首通条件和现有保底不因装箱而改变。

## 已确认边界

- 战斗产出装备、金币、打造材料开普通箱领取，地图和门票等续航资源直接到账。
- 经验、首通解锁与任务进度即时记录。普通刷图每次结束一箱，成功、失败、取消均只包含实际已赚取收益，无收益不发空箱。
- 港口成功一箱，三选一、每项一件装备；在线离线均不自动开箱，未领取金币不可支付港口入场费。
- 直接到账指收益按原规则成立时进入正式资产，不提前授予仅通关才能获得的奖励。

## 已确认资源分类

| 类别 | 结算方式 | 状态与说明 |
| --- | --- | --- |
| 普通装备、底材、传奇/暗金、药剂装备 | 普通箱 | 装备装箱已确认；药剂作为装备实例纳入，不指战斗中药剂充能 |
| 技能石、品质技能石、变异技能石 | 普通箱 | 产生时固定完整实例，不开箱重掷 |
| 天赋珠宝、传奇珠宝 | 普通箱 | 不因使用独立珠宝仓而直接到账 |
| 战斗掉落金币 | 普通箱 | 已确认；未领取不计入钱包 |
| 金属货币、铁屑等打造材料 | 普通箱 | 打造材料装箱已确认 |
| 命能、赤誓收益、苍誓收益、监守印记 | 普通箱 | 按现有打造消费用途细分，作为可消费货币延迟领取 |
| 记忆灰烬 | 普通箱 | 洗点货币装箱；不影响获得经验、升级或获得天赋点 |
| 战功 | 普通箱 | 兑换货币装箱，领取后才可兑换补给 |
| 战争声望、玩法解锁/完成次数、突破与首通进度 | 直接记录 | 声望作为进度而非战功余额，达到条件时立即解锁 |
| 地图、Boss 门票、用于合成门票的碎片 | 直接到账 | 地图/门票已确认；补齐深渊监守者及天垒碎片，沿用自动合票规则 |
| 角色、技能、佣兵经验与现有升级点数 | 直接记录 | 不等待开箱；保持各自原本的奖励条件 |
| 苍誓保底进度 | 直接记录 | 在奖励生成时更新；产出的装备或技能石入本次普通箱，未领取不能再次获得同次保底 |
| 首通固定神话/传奇奖励 | 普通箱 | 生成时登记待领取身份，避免未开箱导致首通重复发奖 |
| 港口专属底材与传奇 | 港口箱 | 已确认，不进入普通箱或普通传奇兑换 |
| 旅程/教学的金币及材料奖励 | 普通奖励箱 | 完成原目标时生成一箱，任务进度直接记录；开箱入口需要前置，避免教学需要材料而玩家无法领取 |
| 玩家主动购买、兑换、打造的产物 | 直接交付 | 这是已支付的操作结果，不再包装第二个箱子；失败/满仓按原事务与恢复规则处理 |
| 开箱过滤或主动卖出/分解所得金币、材料 | 直接到账 | 领取处理的终点，不递归生成宝箱；未开箱物品不得提前卖出/分解 |
| 已有资产、旧档补偿、合法费用退款 | 直接保留或补发 | 不将既有资产反向装箱，不把退款当作新掉落；补偿仍需一次性防重 |

地图打造所用的通用金属仍归打造材料，不因可用于制图而变成直接到账资源；续航直发只覆盖地图、入场票及合票碎片等明确入口资源。

## 奖励来源与汇总

- 普通地图、图内 Boss、深渊、命能花园、赤誓、苍誓、战争前线等同一趟实际收益按分类分流；需装箱部分合并为本趟一个普通箱，不每个节点发箱。
- 独立 Boss、天垒与突破挑战仅包装原规则实际存在的收益，不新增奖励；保留失败或演练的原奖励限制。
- 已完成的图内遭遇收益不因后续整图失败而回滚，尚未满足条件的完成奖励不发。
- 旅程/教学箱是独立来源，和战斗箱共用普通箱全部领取交互，不新增奖励选择。
- 所有箱内技能石、珠宝和装备保存完整实例及稳定身份；开箱使用领取时的过滤设置，不能重新生成掉落。

- `src/Game.Core/Campaign/World/TownEconomy.cs`：AddRewards 与 AddDispositionProceeds 是不同入账入口，需区分战斗掉落与处理收益。

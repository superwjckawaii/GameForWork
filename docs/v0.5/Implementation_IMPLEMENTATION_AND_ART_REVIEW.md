# 2026-09-05 实现与美术复核

> 同日续修的最新状态见 [机制修复与领域重构复核](../v0.4/MECHANICS_REFACTOR_REVIEW.md)。下文保留本报告形成时的边界；遗留项以新复核中的未完成表为准。

## 结论与边界

本次发现了生产战斗未消费已定义装备字段、规则注册被误当作实现、召唤技能直接借用主角伤害，以及母版实际布局与裁剪脚本不符等问题。已修复项见下表。**本报告不宣称所有设计已实现；当前修复任务仍有明确剩余项，不能用自动审计通过替代逐条机制验收。**

2026-09-03 的 Equipment 收口报告验证了目录、生成、保存重绑定和做装入口；它不能证明 109 条附魔/传奇规则或 212 个自然词缀家族的全部实际行为。`EquipmentRuleRegistry` 是元数据表，`EquipmentEffectSnapshot` 的分类也不是执行结果。

## 本轮修复

| 问题 | 生产修改与验证 |
| --- | --- |
| 装备动态字段在队伍快照中丢失 | `EquipmentCombatLoadout` 随主角、佣兵及队伍构筑传入正式 Spatial 模拟；不依赖 UI 当前选中装备 |
| 注册命中却未改变任何状态仍返回成功 | 移除通用 `Triggered=true` 兜底；实际装备状态由 `EquipmentCombatRuntime` 消费 |
| 单系最大抗性提高了所有元素最大抗性 | 各元素分别计算上限；虹彩王印的最大虚空抗性接入；面板与受伤结算共用上限函数 |
| 恢复、偷取、回盾延迟等字段未消费 | 接入最大生命/护盾百分比再生、命中恢复三资源、三资源偷取速率/上限与回盾延迟；小数生命恢复保留余数 |
| 治疗复活零生命角色、减恢复延长偷取 | 普通治疗不复活；偷取按消耗量扣除实例额度，而非按最终恢复量扣除 |
| 法术继承攻击增伤；施法速度不生效 | Skills 区分攻击与法术的增加伤害，施法速度进入行动间隔；装备物理增加与攻击增加分开进入计算 |
| 技能/辅助等级装备词缀未进入实际配置 | 主动和辅助配置增加对应等级，保留等级上限 |
| 传奇/附魔的条件状态没有进入战斗 | 接入受击、移动、击杀、命中、暴击、战吼、支付及药剂事件；条件伤害、计时减伤、层数和部分技能参数实际生效。该项是部分规则覆盖，非 55 件传奇全量完成 |
| 灰烬之心没有实际两次重燃 | 伤害使生命归零时立即处理；同一 tick 多次致命伤害逐次重燃；设置 75%/50% 生命护盾、充满药剂、清除缠根、重置战吼冷却和烈心增益 |
| 所有传奇武器都带余震参数 | 仅回响破誓者具有对应 70% 攻速、70% 延迟余震；不重复对已装配重击配置应用攻速 |
| 园丁筋络做装联动无效 | 预览/执行读取同一装备快照；命能七折向上取整，半边/偏向重铸额外保留原可变自然词缀；定向替换不添加第七条词缀 |
| 半边重铸丢失破裂保护 | 保留词缀数值时也保留破裂家族标记；以连续两次加工验证保护持续存在 |
| 自动召唤技能作为主角直接伤害 | 开战前按组生成普通召唤物及唯一灵兽；使用自己的生命、伤害、命中和攻速；有独立受击目标及回放实体；不再付费反复施放自动召唤石 |
| 炮台没有实体 | 手动部署静止炮台，独立攻击，达到上限移除最老单位；按已确认数据纠正 0.8 秒施法和 4 秒冷却 |
| 末页王庭、逆抗星盘无消费者 | 前者按固定上限前空余名额计算唯一召唤物生命/伤害；后者对法术元素击中选择最低元素抗性再应用对应穿透 |

新增 `ImplementationClosureTests` 包含实际战斗对照、单位与主角武器隔离、自动生成/硬上限、同 tick 两次重燃、园丁费用和额外保留、层数过期与资源恢复测试。

- 最终 `scripts/verify.ps1` 通过：453/453 测试、全部资产门禁、解决方案构建、Godot 4.7.2 导入与无界面启动、四份固定种子审计及提交基准比对。

- `git diff --check` 和 `git lfs fsck --objects` 通过。
- 上述通过证明本轮已覆盖行为和回归门禁；不覆盖下表明确列出的未实现内容，也不等于完整客户端实机视觉验收。

## 美术覆盖与修复

- 清单覆盖 `assets` 下全部 43 张运行时 PNG，共 5,986 个有效裁剪格。逐格检查尺寸、非空、保留空格；独立图标检查唯一性；动画与图标检查透明边距；固定文件哈希防止未经复核的漂移。
- 装备 244 个基底和 55 个传奇/神话逐项生成带目录名称的联系表，复核类别、母版位置和完整轮廓。
- 灵障母版交付实际为 12 列、4 个非等高内容行，底部留白；旧脚本按 13×4 均分，导致串格、残片和半件图标。现在按显式坐标选择主体，再沿整张母版的连通区域提取完整主体。
- 原灵障母版缺少 3 件闪避/灵障盾，已生成独立透明母版并绑定游魂小盾、影缚圆盾、灵迹鸢盾；母版与提示记录一并入库。
- 当前 86 个主动与 98 个辅助技能石改为 184 个稳定唯一索引，图集 10×19。沿用已交付宝石轮廓与颜色，增加唯一纹样；不再哈希映射到旧格或空格。附带 ID→格位清单。
- 角色 620 格、普通敌人 3,224 格、首领 1,488 格全部参与机器边界检查；人工查看全部方向形象联系表。**没有把这些检查称为逐帧人工动画验收，也没有证明全部技能表现与美术语义完全匹配。**
- 可复查命令：`scripts/audit_art_contacts.ps1` 生成 `artifacts/art-audit/`；`scripts/verify_current_assets.ps1` 执行全清单检查；已接入总门禁。

# 第四阶段实施记录

## 验收原则

以实际效果的准确性、可读性和美术质量决定保留、修复或重做。现有图集和表现族是可选实现，不要求优先复用；新增资源需与整体风格一致，并经过实际回放核验。

## 第一批：表现基础

已接入：空间事件的精确起点、终点和表现契约传入 SceneEvent；跨节点统一转换开始/结束时间。危险效果按有效期保留，同一危险的重复伤害脉冲只绘制一次，危险不占装饰特效预算。

普通敌人范围预警使用实际 2000 原始单位半径；持续危险使用各自实际半径和结束时间。圆形按战场两轴投影，锥形按现有判定的 120 度绘制；范围多边形与战场矩形求交，避免越界。主角攻击和受击按事件时间起帧，死亡按本次死亡起点播放。

命中表现使用事件冻结的位置，移除根据当前目标位置插值的虚构飞行。主投射物运行循环输出每步实际轨迹（包含返回），画面使用独立移动事件插值；特殊技能和派生单位已纳入统一身份/动作回归覆盖。轨迹采用值相等，保持确定性回放比较。

已执行真实客户端大窗高档单场景短回放，截图位于 `artifacts/visual-baseline-949e4cd6b3a843749fe55e0a259372fb/case-06.webp`。该样本中范围没有越出战场，但背景对比度、敌人轮廓、阶段反馈辨识度仍需后续修复；此截图不代表动画全量或性能通过。

## 五批顺序

1. 表现事件、几何、持续时间、弹道与动作时钟。
2. 角色、单位与 86 个主动技能逐身份验收。
3. 98 个辅助的可见性、状态与战斗反馈。
4. 敌人、Boss 和港区正式美术与行动表现。
5. UI、宝箱动效与回放矩阵。

自动测试只证明数据和回放选择规则；视觉质量需要引擎画面证据。第五阶段继续完整性能长测及经济验证，旧机制集中修复仍在第六阶段。

## 第二批试做：角色与单位共性问题

- 删除静止角色、敌人和队友的随机位移，位置读取实际帧；队友移动使用帧间插值。
- 队友不再复制主角动作和方向，按自身事件选择动作、朝向和起帧时间；炮台静止时不再滑步。
- 主动技能按正式攻击标签选择攻击或施法动作。幽魂飞刃在正式规则中属于攻击，保留攻击动作；链雷播放施法。
- 主角、幻身、佣兵和召唤单位的一次性动作不循环；缩短受击反馈的占用窗口，避免持续盖住攻击动作。
- 投射物移动事件不再触发招牌技能的第二段结束特效。

真实客户端试做回放：`artifacts/visual-baseline-7922a93edb8942cfb9f4b5e5cf79e1d2/case-06.webp`。这是单场景观察，背景和敌人轮廓仍不够清楚；动态长测仍属于后续整体美术验收，不阻塞第二批的事件/动作实现收口。

## 本轮验证

完整 Release 门禁通过，867/867 测试通过，构建零警告零错误；资源、Godot 导入/启动及既有审计通过。新增测试覆盖长预警、零装饰预算、多危险、重复脉冲、跨节点身份和到期移除，以及技能攻击/施法动作分类。真实回放只覆盖上述单场景，完整美术质量验收仍在进行。

## 第二批续作：播放时间与弹道边界

- 有表现契约的技能按契约开始/结束时间计算播放进度，不再按固定图集时长提前截断；未来开始的事件不提前展示。
- 投射物沿记录的折线逐段插值，保留中间拐点和返回段，不再直接连接首尾。轨迹没有逐点时间戳，因此按总路径长度匀速插值；当前生产事件仍以每步两点轨迹为主。
- 主动技能查找改为非异常查询；全 86 个技能的攻击/施法分类及未知身份回退纳入测试。
- 定向测试 14/14、完整 Release 门禁 867/867 通过。
- 隔离客户端短回放完成，错误日志为空：`artifacts/visual-baseline-dedd9bef77634b39bc110ab195292b56/case-06.webp`，同时产出 30 帧序列。已检查单张画面；背景与敌人轮廓辨识度仍待修复，未据此宣称全技能动态或性能验收通过。

## 第二批续作：移除辅助标签伪造的技能形态

- 空间战斗及紧凑视图删除 `DrawSupportLayers` 和辅助位标记解析入口，不再因装有辅助就凭空画额外投射线、连锁折线、返回环、范围环或重复环。
- 同时移除该入口中未经事件证实的异常、护盾、触发和召唤光环装饰；原有状态图标与战斗反馈仍保留。这里只清理误导表现，不改辅助战斗机制，不代表 98 个辅助已完成验收。
- 暴击强调改为读取真实伤害事件的独立 `critical` 标记并要求伤害大于零，不再依赖是否装备暴击辅助。测试覆盖无辅助暴击、辅助标签但未暴击、零伤害及相似字符串。
- 本项与第三批辅助可见性有交集，是为了避免第二批技能形态验收继续受到旧叠层干扰；辅助机制本身仍按第三批清单继续验收。
- 本次完整 Release 门禁通过，872/872 测试通过，构建零警告零错误。隔离短回放完成、错误日志为空，已检查 `artifacts/visual-baseline-b33763f8f0ca4cfa980767f93e9eacd1/case-06.webp`；该单场景仅确认客户端仍正常绘制，不证明所有辅助反馈已通过视觉验收。

## 第二批收口

86 个主动技能已按正式战斗标签覆盖攻击/施法动作分类；主角、敌人、队友、幻身、佣兵和召唤单位均按自身事件、方向、位置和动作时钟绘制。自动化覆盖事件生命周期、实际暴击、投射折线/返回和未知技能回退；第二批代码与回归验证完成。逐帧长时间美术观感属于第四阶段整体回放，不作为本批的伪通过条件。

## 第三批：98 个辅助验收

98 个辅助已逐项通过正式定义、运行时资格判定、表现层存在性和事件反馈矩阵检查；没有资格的辅助不会被强制附加到不兼容技能。异常、格挡、守卫、反击和召唤反馈均由真实事件触发。客户端逐帧美术观感仍需人工回放，因此第四阶段的代码与自动化验收完成，纯视觉长测不宣称自动通过。

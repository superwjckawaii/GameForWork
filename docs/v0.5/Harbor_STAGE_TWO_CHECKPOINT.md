# 沉金港第二阶段：流程原型接续

日期：2026-09-09。第二阶段流程原型、普通战利品箱与港口装备第二批已接入，并通过完整Release门禁；动画全量优化和经济平衡仍留在后续阶段。当前第二批修改尚未提交或推送。

## 已接入

- 远征页面新增沉金港页签。百级突破后，空闲主角队伍和佣兵远征队均可选择三档难度、次数及失败继续；一次性支付1000/3000/8000金币。地图、Boss挑战及批量入队不能占用正在港口行动的队伍。
- 固定外港栈桥、沉没仓区、宝库内港三段，复用SpatialCombatRunner的正式攻击、承伤、控制、恢复和避险。每段清敌后实际移动至宝库，自动交互2秒，追击者入场后移动至出口，抵达即可脱离追击；周期危险在移动与交互期间继续结算。300秒全局时限；没有属性评分胜负、路线选择、提前撤离或途中发装备。
- 权威行动结果与空间帧在开局冻结，按实际经过时间推进，与既有地图的确定性回放结构一致。移速改变移动步长和暴露时间，防御影响真实承伤。不是等待固定计时后掷一次成功率。
- 保存格式26可读取原格式25。进行中保存行动ID、种子、已支付费用、完整权威结果、进度及重复设置；恢复不重新计算结果、不重扣费。校验失败的行动终止并按确认费用退还一次，不发箱；正常取消不退费。停止重复完成当前局，立即放弃终止当前局。
- 成功时生成唯一港口箱，候选实例及顺序已冻结；离线不自动开箱，未开箱不妨碍下一次派遣。手选一项后锁定保护，不进入自动卖出/分解；仓满使用现有无容量上限的恢复箱，重复领取失败。未虚构“恢复箱已满”规则；重复身份等接收失败时保留宝箱。
- 港口箱已扩展为至少一个特殊底材加两个按难度抽取的候选位；难度1/2/3的传奇候选概率为10%/20%/35%，同箱按候选身份去重，8件专属传奇只从成功港口箱生成。
- 8件港口专属传奇已进入正式目录并接入固定属性、战斗条件、附魔/存档重绑定和来源隔离；三潮吊坠支持三条不同合法附魔，普通传奇兑换与命铸不会生成这些专属装备。
- 18件港口底材均已进入统一装备目录；第二批的静潮兜帽、压舱重铠、破浪护手、涉潮长靴、逐浪/守港指环、三潮吊坠、回流束带和定锚重带已接入实际战斗、药剂、异常和打造消费者。自然掉落及遭遇奖励池明确排除harbor标签，没有另建平行物品系统。
- 新增SpatialPresentation结构，携带动作身份、起止时间、形状、半径、方向、轨迹。港口移动、自动交互与周期危险使用该结构，原型页按实际空间数据绘制并裁剪。旧战斗事件尚未全部改造，留给第四阶段，不声称全动画已修复。

## 原型边界

- 当前每箱三选一已覆盖完整18件特殊底材池与8件专属传奇池；底材品质按难度10%/25%/50%概率掷20，传奇品质为10%。权重仍是初始配置，需第五阶段结合实际耗时和金币流做平衡审计。
- 三段名称和行动目标已落地；9普通、3精英、3首领已在第三阶段接入专属稳定身份，并继续复用正式战斗消费者。
- 原型战场使用明确标识的几何回放；三件装备暂复用对应既有图标，未新增或伪称专属美术。第四阶段进行完整动态验收。原有越界圆环、长帧和音频错误仍未关闭。
- 普通刷图装备、金币和金属材料已汇总为普通战利品箱，经验、地图、技能石和任务进度仍即时结算；开箱时沿用过滤、仓储、恢复、卖出和分解边界。
- 操作与快照沿用现有主线程/后台保存边界；领取与扣费在同一会话状态转换内完成。断电恢复以上一次已提交快照为准，不承诺未保存操作也能恢复。

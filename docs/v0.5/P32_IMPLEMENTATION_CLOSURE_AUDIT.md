## 复核中修复的问题

1. 旧腐化JSON把效果文本与适用装备列写反，运行时因此无法选出正确候选；现通过兼容访问器纠正语义，37条词缀全部具有结构化组件与独立掷值。
2. 腐化装备此前只保存腐化名称，属性计算和旧存档恢复不读取效果；现已接入局部武器、四种局部防御、全局汇总与确定性重绑定。
3. 传奇固定词缀此前每段只解析一个字段，大量复合词缀落为 `None`；现55件传奇/神话逐段生成全部效果组件，未知文本直接启动失败，不再静默兜底。
4. 新增重弦战弓系四件底材被错误标记为 `Shield/OffHand`；现改为 `TwoHandWeapon/MainHand`。
5. 召唤物、构装体和幻身上限此前共用 `AdditionalUnitMaximum` 占位；现分别写入三个专属效果种类。
6. 正式做装名称与旧内部枚举不一致，导致神铸、祝铸、精磨和腐化进入无变化分支；现名称映射完整，并将连接重铸与稳固增连拆成各自算法。腐化品质按5～10、损伤品质归零并等权移除非破裂词缀执行。
7. 旧P19目录与浏览器、P24装备目录、P30装备补丁、无生产调用的P25传奇近似表已删除；UI面板与美术索引移除阶段号类型名。

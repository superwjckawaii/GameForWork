# P4 空间群战与角色工坊规格

## 1. 空间群战

- 每个场景节点继续使用 `12×24` 逻辑网格，单位位置使用千分之一格的定点数表达，20 Hz 权威模拟与 60 FPS 表现分离。
- 同一节点的完整怪群同时生成；普通、精英、Boss 节点和安全/深渊地图使用不同人数区间。
- 单位拥有实际位置、移动速度、软碰撞、攻击范围、理想距离、当前目标与攻击间隔。
- 近战接近目标，远程维持距离；索敌综合 Boss、危险度、距离、剩余生命和仇恨。
- 节点内全部敌人死亡后才结算并开放下一个节点；在线、离线和重放消费同一条确定性时间线。

## 2. 空间技能

- 主角战斗栏上限为三个主动攻击技能，战吼作为自动工具技能。
- P4 首批攻击技能为重击、裂地横扫与幽魂飞刃。
- 重击使用真实近战范围；裂地横扫命中实际扇区内的目标；幽魂飞刃具有飞行时间并在连锁半径内选择未命中过的最近目标。
- 移速同时影响节点间旅行和节点内走位；攻击动作期间不能免费滑行。

## 3. 总览表现

- 镜头自动适配完整战场，绘制所有存活敌人、移动、当前目标、精英/Boss 标记和小血条。
- 当前目标、精英和 Boss 显示重点信息；密集伤害数字按时间和目标合并。
- 空间技能分别使用近战弧、地裂扇区、飞行投射物和连锁线表现。

## 4. 金属通货工坊

- 装备制作不再消耗金币和铁屑，改为固定消耗功能明确的金属通货。
- P4 实装淬刃铁、守壁钢和活血银；混沌金、神铸银、破溃钢进入钱包与掉落体系，为后续配方保留稳定 ID。
- 工坊迁入“角色与物品 → 装备与仓库”，支持仓库、整理背包和已装备物品原位加工。
- 全局最后选中的合法物品作为制作目标；配方显示金属消耗、适用性、失败原因和制作前后对比。

## 5. 装备栏

- 装备备栏扩宽并按人体对称分布；主副手远离身体轮廓，首饰、腰带、鞋和药剂保持清晰层级。
- 图标使用居中对齐；空槽显示名称；双手武器覆盖副手；装备槽之间支持合法交换和完整回滚。
- 合法拖放使用亮色目标框，非法目标使用红色提示并说明原因。

## 6. 交付

P4 采用四个提交：空间群战核心、空间技能与 AI、群战总览、角色工坊与装备栏。格式版本升级并兼容旧档。Debug、Release、Godot 导入与启动检查通过后直接推送 `master`。

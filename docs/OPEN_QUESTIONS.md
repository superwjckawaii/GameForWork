# 待讨论与开发决策

> 更新日期：2026-08-27  
> 本文只列出尚未确定的内容。已确认设计以 `GAME_DESIGN_BASELINE.md` 为准。

## 1. 窗口与桌面体验

- 正常窗口、最小窗口和托盘模式的具体尺寸。
- 最小窗口保留哪些交互，哪些操作必须展开窗口。
- 是否支持置顶、贴边吸附、透明度和无边框模式。
- 小窗口同时展示战斗、城镇与第二远征队状态的布局。
- 通知等级、静音反馈、Boss 或队列停止时的提醒方式。
- 2 倍速按钮、暂停规则和窗口失焦时的行为。

## 2. 像素美术规格

- 原生渲染分辨率和整数倍缩放策略。
- 战斗角色、Boss、建筑和 UI 图标的像素尺寸。
- 斜俯视场景使用的投影方式与地块规格。
- 角色八方向或四方向表现、基础动画帧数与换装表现范围。
- 首个垂直切片所需的角色、敌人、建筑和特效资产清单。

## 3. 技术栈

- 游戏引擎与语言。
- Windows 打包、自动更新和崩溃恢复方式。
- 正常渲染、后台运行和离线结算的统一模拟架构。
- 确定性随机种子、固定时间步和战斗回放格式。
- 数据驱动配置、模组边界和 DLC 内容加载方式。
- 存档格式、版本迁移、备份、防损坏与 Steam Cloud 等云存档是否接入。
- 性能目标、内存目标、最小系统要求与耗电控制。

## 4. 数值与公式

- 四种基础属性的每点收益。
- 护甲、闪避、命中、灵障、护盾和法术压制的完整公式。
- 体魄提供攻击伤害增加的具体比例。
- 等级经验曲线、地图阶级与怪物等级映射。
- 佣兵成长潜力的档位和精确差距。
- 多人佣兵队的敌群和奖励缩放公式。
- 词缀档位、出现权重、传奇保底次数和制作成本。
- 掉落数量、仓库容量、金币产消和 48 小时产出上限。

## 5. 内容细化

- 六种主要异界机制的完整节点、奖励和失败规则。
- 沉金港与无光矿脉的独立循环。
- 赤月、苍星祭坛的奖励池和风险选择。
- 首批地图、怪物家族、普通 Boss 与攻坚 Boss 清单。
- 四职业十二进阶的具体核心节点。
- 首批主动技能、辅助技能、传奇与神话装备清单。
- 主角出身切换的世界观解释与具体成本。
- “断界之夜”的开发内部唯一真相。

## 6. 产品与发布

- 正式名称与商标检查。
- 是否首先发布本地独立版本或接入 Steam。
- 买断价格、Demo、抢先体验和 DLC 原则。
- 成就、手柄、语言和无障碍支持范围。
- 原型、首个测试版、1.0 的人力和时间范围。

## 7. 下一轮建议顺序

1. 窗口形态与低打扰交互。
2. 像素规格与首个可视垂直切片。
3. 引擎、语言、存档和离线模拟架构。
4. 最小可玩版本范围与里程碑。
5. 数值原型和首批内容表。

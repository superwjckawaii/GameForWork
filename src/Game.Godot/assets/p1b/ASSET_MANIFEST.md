# P1B Generated Asset Manifest

All raster assets in this directory were generated with the built-in OpenAI image generation tool on 2026-08-27 and then copied into the Godot project. No external runtime URL is required.

## Assets

- `town/frostgate-town.png`: 16:9 isometric dark-fantasy frontier town, warm forge lights, ancient cyan portal, no text or UI.
- `combat/abyss-floor.png`: 16:9 empty isometric basalt arena with cyan chasm light and restrained red corruption cracks.
- `characters/p1-character-atlas.png`: transparent character/enemy concept atlas containing hero variants, equipment looks, cantor mercenary, regular enemies, elite mutation and abyss warden boss.
- `ui/item-atlas.png`: transparent five-icon strip containing two-handed weapon, body armor, helmet, ring and life flask.

## Shared generation constraints

- Highly polished hand-authored-looking pixel art with crisp pixel clusters.
- Dark-fantasy palette and strong silhouettes readable at `384×216`.
- No text, labels, logos, watermarks or UI frames.
- Town uses warm amber against cold dusk; expedition uses cold navy/cyan with restrained blood red.

The exact structured prompt set is recorded in the Codex development handoff for this P1B iteration. Generated source files are tracked through Git LFS.

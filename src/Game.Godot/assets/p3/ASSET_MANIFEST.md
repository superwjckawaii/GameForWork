# P3 standalone pixel assets

Generated with the built-in image generation workflow for the P3 visual slice. The runtime uses every file as an independent texture, so no neighboring atlas cell can bleed into a mercenary or act preview.

- `characters/rune-mercenary.png`: transparent standalone rune-chanter mercenary.
- `campaign/act-1-ash-camp.png`: act-one ash camp.
- `campaign/act-2-frost-town.png`: act-two frozen military town.
- `campaign/act-3-drowned-crypt.png`: act-three drowned crypt.
- `campaign/act-4-crimson-foundry.png`: act-four crimson foundry.
- `campaign/act-5-void-citadel.png`: act-five void citadel.

All six files use compact, hard-edged pixel treatment with no embedded labels or UI.

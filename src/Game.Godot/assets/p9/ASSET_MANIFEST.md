# P9 low-density pixel assets

Generated with the built-in image generation workflow and connected as project-bound Godot textures.

- `town/p9-town-district.png`: fixed dark-fantasy district with seven readable building silhouettes around a central plaza. Runtime overlays the Chinese building buttons.
- `characters/p9-mercenary-atlas.png`: four-column chunky pixel portrait atlas for guardian, ranger, cantor, and arcanist. Runtime crops one column per archetype.
- `ui/p9-metal-atlas.png`: exact 5×4 icon atlas for the nineteen persistent metals; the last cell is intentionally empty. Runtime crops by the stable enum index.

Prompt set: dark-fantasy, low-density taskbar-readable pixel art, hard silhouettes, limited palette, no embedded labels. The first over-detailed mercenary draft was rejected and is not included in the repository.
